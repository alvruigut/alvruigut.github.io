Windows Exploit Suggester

Los exploits de kernel pueden provocar inestabilidad o pantallazo azul. En pentest real, priorizar validación de versión/parches y evidencias antes de ejecutar PoCs invasivas.

Kali: Entorno Virtual

python3 -m venv .venv
source .venv/bin/activate

Kali: Clonar WES

git clone https://github.com/strozfriedberg/Windows-Exploit-Suggester.git

CMD: Copiar HotFixes del sistema

systeminfo # Copiamos todo el contenido

Kali: Ejecutar WES

# Actualiza la bd
python2 windows-exploit-suggester.py --updates
# Ejcuta el reconocimiento de systeminfo
python2 windows-exploit-suggester.py --database <file.xlsx> --systeminfo sys_info.txt

# Priorizar Exploits Públicos [E] frente a Módulos de Metasploit [M].
# Buscar en ExploitDB los EDB-ID de la vuln y buscar el exploit en el link abajo
