Modo de empleo

NMAP scripts NSE

# Utilizar script específico
nmap  -p 21 <ip_objetivo>  --script=ftp-anon

# Utilizar categorías
nmap -p22 192.168.1.1 --script="vuln"
nmap -p22 192.168.1.1 --script="vuln and/or safe"

# Utilizar todos los scripts relacionados con el serivicio ftp
nmap --script "ftp-*" -p 21 <ip_objetivo>

Se puede localizar todos los scripts con el siguiente comando: locate .nse

El parámetro -sC ya lanza algunos scripts básicos
