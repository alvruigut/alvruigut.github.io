Procesos y servicios

Procesos, servicios, tareas programadas y aplicaciones instaladas ayudan a localizar software vulnerable, rutas modificables y ejecuciones con cuentas privilegiadas.

Meterpreter

ps # Procesos en ejecución 
pgrep explorer.exe # Localizar un proceso
migrate 2252 # Migrar a ese proceso

CMD

ps # Procesos en ejecución 
tasklist /SVC  # Procesos en ejecución en el sistema

net start # Servicios iniciados
wmic service list brief # Servicios en ejecución
schtasks /query /fo LIST /v # Tareas programadas

## Programas Instalados
dir /a "C:\Program Files", "C:\Program Files (x86)"
reg query HKEY_LOCAL_MACHINE\SOFTWARE

PowerShell

Get-WmiObject Win32_Service | Select-Object Name, StartName  # Servicios con cuentas privilegiadas
