SSH

Escenario

Kali: 192.168.10.10

Máquina 1: 192.168.10.20 / 192.168.20.10

Máquina 2: 192.168.20.20 / 192.168.30.10

Máquina 3: 192.168.30.20

Dynamic Port Forwarding

Kali: abrir un SOCKS hacia Máquina 1

ssh -D 8080 usuario@192.168.10.20

Configurar Proxychains

nano /etc/proxychains4.conf

socks5  127.0.0.1 8080

Kali: comprobar visibilidad con la red azul

proxychains nmap -sT 192.168.20.20

Segundo pivote

Crear un segundo puente hacia Máquina 2

ssh -D 9090 -f -N usuario@192.168.20.20

-D 9090 crea un proxy SOCKS dinámico en Kali en el puerto 9090.

-f manda el proceso a segundo plano.

-N no abre shell interactiva; solo crea el túnel.

Configurar cadena de proxies

nano /etc/proxychains4.conf

socks5  127.0.0.1 9090
socks5  127.0.0.1 8080

Kali: comprobar visibilidad con la red verde

proxychains firefox
proxychains nmap -sT 192.168.30.20

Local Port Forwarding

Exponer en Kali un servicio local del objetivo

ssh -L <kali_port>:127.0.0.1:<target_port> user@ip
