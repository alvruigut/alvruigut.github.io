Shadow

/etc/shadow almacena hashes de contraseñas locales. Leerlo requiere root o permisos equivalentes, y el cracking debe hacerse solo dentro de laboratorio o pentest autorizado.

Los hashes en Linux se almacenan en el archivo /etc/shadow con el formato $id$salt$hash. El id, el número entre símbolos $, indica el algoritmo usado.

Solo es legible como usuario root

- $1 → MD5

- $2 → Blowfish / bcrypt

- $5 → SHA-256

- $6 → SHA-512

Kali: Como root podemos leer el fichero /etc/shadow

cat /etc/shadow

# Nos copiamos el hash: root:$6$sgewtGbw$ihhoUYASuXTh7Dmw0adpC7a3fBGkf9hkOQCffBQRMIF8/0w6g/Mh4jMWJ0yEFiZyqVQhZ4.vuS8XOyq.hLQBb.:18348:0:99999:7:::

# Desde kali desciframos el hash con john con el formato 512 por el id:6

# Copiamos el hash en un txt
nano hash.txt
john --format=sha512crypt --wordlist=/usr/share/wordlists/rockyou.txt hash.txt
john --show hash.txt
