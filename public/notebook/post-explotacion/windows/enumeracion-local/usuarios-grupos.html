Usuarios y grupos

La enumeración de usuarios, grupos, privilegios y sesiones permite entender el contexto de acceso y detectar permisos útiles dentro del host o dominio.

CMD

## Sobre Usuario actual
whoami         # Muestra el usuario actual.
whoami /priv   # Lista los privilegios del usuario actual.
whoami /groups # Muestra los grupos a los que pertenece el usuario.

## Usuarios
net user              # Lista los usuarios locales del sistema.
net user administrator # Muestra información del usuario 'administrator'.

## Grupos
net localgroup                     # Lista los grupos locales.
net localgroup Administrators      # Muestra los miembros del grupo Administrators.

net group "Domain Admins" /domain  # Lista los administradores del dominio (solo en entorno AD).
net group administrators           # Muestra el grupo Administrators del dominio (si aplica).

quser #Usuarios logueados
qwinsta #Sesiones remotas
klist sessions #Tickets de Kerberos
net accounts # Políticas de contraseñas

dir C:\Users        # Lista los directorios de perfiles de usuarios.
history             # Muestra el historial de comandos en PowerShell.

Meterpreter

getuid # Usuario
getprivs # Privilegios
