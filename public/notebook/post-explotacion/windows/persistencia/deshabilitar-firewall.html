Deshabilitar Firewall

Deshabilitar el firewall reduce defensas del sistema y puede afectar a la disponibilidad. Úsalo solo en laboratorio o cuando el alcance del pentest lo permita de forma explícita.

CMD: Deshabilitar Firewall

netsh advfirewall set allprofiles state off
