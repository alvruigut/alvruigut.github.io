Enumeración con Metasploit

Metasploit incluye módulos de post-explotación para recolectar información básica del host. Conviene revisar el alcance de cada módulo antes de ejecutarlo.

Comandos

use post/windows/gather/win_privs # Chequeo de enumeración
use post/windows/gather/enum_logged_on_users
use post/windows/gather/checkvm # Comprueba si el host es un VM 
use post/windows/gather/enum_applications # Apps en el host
use post/windows/gather/enum_av_excluded # Enumera el AV
