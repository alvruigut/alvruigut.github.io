Enumeración

Enumerar shares

# Probar siempre con null session, usuario guest y credenciales válidas si existen

Permisos en shares

smbmap -H <ip> 
smbmap -H <ip> -u 'null'
smbmap -H <ip> -r <recurso>/<directorio>
smbmap -H <ip> -u guest -p "" -d .

Acceso a shares

smbclient //<ip>/<recurso> -N 
smbclient //<ip>/<recurso> -U <usuario>
smbclient //<ip>/<recurso> -U <usuario>%<contraseña>

Descargar contenido del Share

# Null Session
smbclient -N //<ip_target>/<Share>/ -c "recurse; prompt; mget *;"
# Credenciales
smbclient //<ip_target>/<Share>/ -U <user> -c "recurse; prompt; mget *;"

Acceso SMB

Cuando validamos credenciales con crackmapexec/nxc, el indicador Pwned suele significar que el usuario tiene privilegios suficientes para ejecutar comandos remotos en esa máquina, normalmente por pertenecer al grupo de administradores locales. Aun así, conviene confirmarlo porque depende del protocolo, la versión de la herramienta y las políticas del host.

#!/bin/bash

ip_target="192.168.1.10"
wordlist="/ruta/shares.txt"

while read -r share; do
	if smbclient -N "//$ip_target/$share" &>/dev/null; then
		echo "Recurso con null session encontrado: $share"
	fi
done < "$wordlist"
