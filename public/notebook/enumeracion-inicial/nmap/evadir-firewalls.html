Evadir Firewalls

Técnicas de evasión de Firewalls

# Fragmentación de paquetes — enviar paquetes fragmentados para intentar evadir filtros/IDS.
nmap -p22 <target> -f

# Filtrar paquetes fragmentados en Wireshark — muestra fragmentos con el flag MF (more fragments).
ip.flags.mf == 1

# Alterar el MTU para probar bloqueos por tamaño de paquete (debe ser múltiplo de 8).
nmap -p22 <target> --mtu 8

# Usar “decoys” para que el escaneo parezca venir de varias IPs y confundir firewalls/IDS.
nmap -p22 <target> -D <ip1>,<ip2>,<ip3>,<ip4>

# Decoys masivo + top ports + verbose (ejemplo con muchas IPs).
nmap --top-ports 100 <target> -D <ip1>,<ip2>,...,<ip100> -v -n

# Cambiar el puerto de origen para parecer tráfico desde un puerto permitido.
nmap -p22 <target> --open -v -n --source-port 53

# Añadir bytes de datos a cada paquete para eludir reglas basadas en tamaño.
nmap -p22 <target> --data-length 24

# Falsificar la dirección MAC para parecer un fabricante/dispositivo concreto.
nmap -p22 <target> --spoof-mac Del
