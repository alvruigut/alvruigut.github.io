53 - DNS

Domain Zone Transfer

Enviar consultas DNS simples permite comprobar si el servidor expone información útil. Una transferencia de zona (AXFR) mal configurada puede revelar el espacio de nombres DNS de la organización objetivo y ampliar la superficie de ataque.

Enumeración de servidores

# Configurar dominio (htb.local) a la ip target en el etc hosts
dig @<ip_target> htb.local # Ver que funciona y devuelve dominios
dig @<ip_target> htb.local mx # Enumera servidores de correo
dig @<ip_target> htb.local ns # Enumera name servers

Enumeración para Domain Zone Transfer para obtener subdominios

dig @<ip_target> htb.local axfr
