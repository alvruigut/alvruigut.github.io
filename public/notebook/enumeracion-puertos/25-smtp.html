Enumeración

Enumerar comandos válidos: VRFY, EXPN y RCPT TO

telnet demo.ine.local 25
HELO <attacker.xyz> # Cualquier nombre.xyz
EHLO <attacker.xyz>
HELP

Enumerar un Usuario

# Verificar con VRFY
VRFY admin 
VRFY admin@openmailbox.xyz 
# Verificar con EXPN (permite enumerar usuarios por listas como 'all')
EXPN admin 
EXPN all
# Verificar con RCPT TO
MAIL FROM:test@openmailbox.xyz 
RCPT TO:admin

Enumerar Usuarios

smtp-user-enum -U /usr/share/commix/src/txt/usernames.txt -t demo.ine.local

# -M se puede cambiar también por RCPT o EXPN
smtp-user-enum -M VRFY -U /usr/share/commix/src/txt/usernames.txt -D <DOMINIO.COM> -t <IP_TARGET>

Enumerar Servidor SMTP en la Nube

GitHub o365spray para Microsoft Office 365

Validar si el dominio usa Office 365

python3 o365spray.py --validate --domain <domain.xyz>

Identificar nombres de usuarios

python3 o365spray.py --enum -U <users.txt> --domain <domain.xyz>

Si los servicios en la nube admiten los protocolos SMTP, POP3 o IMAP4, podríamos intentar rociar contraseñas, pero estas suelen estar bloqueadas.

Fuerza bruta sobre lista usuarios

python3 o365spray.py --spray -U <usersfound.txt> -p <'March2022!'> --count 1 --lockout 1 --domain <domain.xyz>

Herramientas como MailSniper para Microsoft Office 365 o CredKing para Gmail pueden ayudar en auditorías autorizadas.

Open Relay

Un servidor open relay permite enviar correos hacia terceros sin controles adecuados. En un pentest autorizado se valida el riesgo de suplantación y abuso para phishing, sin enviar campañas reales fuera del alcance.

Verificar si se permite open-relay

nmap -p25 -Pn --script smtp-open-relay 10.10.11.213
# smtp-open-relay: Server is an open relay (14/16 tests)

A continuación, podemos utilizar cualquier cliente de correo para conectarnos al servidor de correo y enviar nuestro correo electrónico.
