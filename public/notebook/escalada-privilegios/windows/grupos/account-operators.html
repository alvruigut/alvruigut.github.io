Account Operators

DNS Admins Exchange Windows Permissions

Permiten crear usuarios

Permite añadir usuarios a grupos que no sean administradores

CMD: Crear usuario y Añadirlo a DnsAdmins

net user <user> <password> /add
net localgroup "DnsAdmins" <user> /add
# Si no se añade, reiniciar la terminal

CMD: Crear usuario y Añadirlo a Exchange Windows Permissions

net user <user> <password> /add
net group "Exchange Windows Permissions" <user> /add
