Cambiar contraseñas de usuarios

Cambiar contraseñas es una acción intrusiva que puede interrumpir el servicio y dejar evidencia clara. En un pentest real debe estar expresamente autorizado y documentado.

Como usuario NT AUTHORITY/SYSTEM modificamos la contraseña del user Administrator

net user Administrator password_123
