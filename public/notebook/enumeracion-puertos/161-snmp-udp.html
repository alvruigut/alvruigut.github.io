161 - SNMP (UDP)

Simple Network Management Protocol: Protocolo que monitoriza y administra equipos en una red (servidores, routers, switches, impresoras, etc.).

Para leer información normalmente necesitas una community string. La típica es public (solo lectura) y private (a veces escritura). No es cifrado ni autenticación fuerte en SNMPv1/v2c; funciona más como un secreto compartido.

Recorrido por SNMP

# Enumerar UDP
nmap -sU --top-ports 100 --open -vvv -n 10.129.230.96 
# Enumerar versión
nmap -sU -sCV -p161 10.129.230.96
# Fuerza bruta de community strings. Suele aparecer public
onesixtyone -c /usr/share/seclists/Discovery/SNMP/common-snmp-community-strings.txt 10.129.230.96
# Enumerar SNMP
snmpwalk -v1 -c public 10.129.230.96 
snmpbulkwalk -v2c -c public  10.129.230.96 # TOP (Enumera todo)

Comandos útiles

# Exportar output mientras lo vemos por pantalla
snmpbulkwalk -v2c -c public  10.129.230.96 | tee snmp_scan
# Usar MIBs (se puede enumerar con números o strings)
snmpbulkwalk -v2c -c public  10.129.230.96 1.3.6.1.2.1.1.1.0
snmpbulkwalk -v2c -c public  10.129.230.96 SNMPv2-MIB::sysDescr
# Excluir output
snmpbulkwalk -v2c -c public  10.129.230.96 1.3.6.1.2.1.25.4.2.1.5 | grep -v '""'
# Modos diferentes
snmpwalk -v 1 -c public <ip_target>  NET-SNMP-EXTEND-MIB::nsExtendOutputFull
snmpbulkwalk -v2c -c public  <ip_target> NET-SNMP-EXTEND-MIB::nsExtendObjects
