Clave PuTTY

Las claves PuTTY (.ppk) pueden convertirse a formato OpenSSH para autenticación SSH. Guarda y usa claves solo dentro del alcance autorizado.

Instalar Putty

sudo apt install putty-tools

Convertir putty a id_rsa

puttygen <putty_key.ppk> -O private-openssh -o <id_rsa>

Conectarnos al target vía SSH

chmod 600 id_rsa
ssh -i id_rsa root@<ip_target>
