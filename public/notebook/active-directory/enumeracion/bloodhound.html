BloodHound

BloodHound permite modelar relaciones del dominio y encontrar caminos entre usuarios, grupos, equipos, sesiones y privilegios.

Cargar base de datos NEO4J

Comandos

# Iniciar servicio Neo4j: http://localhost:7474
sudo neo4j start
# Abrir BloodHound con USUARIO NORMAL
bloodhound
# neo4j:<neo4j_password>

Recolectores

Linux - BloodHound.py

BloodHound.py GitHub para Linux

Nos clonamos el repositorio

git clone https://github.com/dirkjanm/BloodHound.py

Extraer datos del AD

bloodhound-python -u <username> -p <password> -ns <ip_dc> -d <dominio.local> -c all
# Alternativa
nxc ldap <ip_target> -u <username> -p <password> --bloodhound -c All -ns <ip_dc>
# Proxychains
proxychains bloodhound-python -d <domain> -u <u> -p <p> -c all -ns <ip_dc> --dns-tcp --zip
