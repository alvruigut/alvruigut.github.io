Sudoers

/etc/sudoers es el archivo de configuración que define quién puede usar sudo y qué comandos puede ejecutar como otro usuario, normalmente root.

Listar comandos que podemos ejecutar como otro usuario

sudo -l

# Output
student ALL=(root) NOPASSWD: /usr/bin/man

GTFOBins SUDO

Ejecutar binarios permitidos como otro usuario

# Para usuario pepe
sudo -u pepe git -p help config

# Para root
sudo git -p help config

Binarios No Contemplados en GTFOBins

mcedit

sudo mcedit

# Comandos
F+9

# Ruta
File -> User menu -> Invoke 'shell'
