Un exploit aprovecha una vulnerabilidad concreta y el payload define qué acción se ejecuta si la explotación funciona. Por ejemplo, se puede usar un payload de Meterpreter o una reverse shell para recibir una sesión en la máquina objetivo.

Payloads

show payloads

set payload <number>
set payload windows/meterpreter/reverse_tcp

Es importante diferenciar entre comprobar una posible vulnerabilidad y explotarla directamente. Antes de lanzar un exploit conviene validar el servicio con módulos auxiliary, opciones check cuando existan y la información de enumeración disponible, para reducir ruido y evitar impactos innecesarios.

 sudo mv db_autopwn.rb /usr/share/metasploit-framework/plugins/

 msfconsole -q

 msf6 > db_autopwn
