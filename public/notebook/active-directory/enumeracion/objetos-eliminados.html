Objetos eliminados

Los objetos eliminados del dominio pueden revelar usuarios, atributos históricos o información útil si se dispone de permisos para consultarlos.

Flujo Módulo ActiveDirectory

# Importar Módulo
Import-Module ActiveDirectory
# Enumerar Objetos Eliminados
Get-ADObject -Filter 'isDeleted -eq $true' -IncludeDeletedObjects
# Restaurar Objeto
Restore-ADObject -Identity <GUID>
# Habilitar Cuenta
Enable-ADAccount -Identity cert_admin
# Cambiar contraseña
Set-ADAccountPassword -Identity cert_admin -Reset -NewPassword (ConvertTo-SecureString "cert_admin123" -AsPlainText -Force)
# Eliminar Usuario
Remove-ADUser -Identity cert_admin -Confirm:$false

Flujo PowerView (No Probado)

# Importar Módulo
