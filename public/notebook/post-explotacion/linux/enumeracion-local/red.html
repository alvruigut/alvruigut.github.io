post-explotación / linux / enumeración local

Red

La enumeración de red local ayuda a descubrir rutas, interfaces, DNS, hosts internos y servicios que solo escuchan desde localhost o redes privadas.

Comandos de red

# BASH
route                # Tabla de Enrutamiento
ip route             # Tabla de Enrutamiento
netstat -r           # Enumeración de red
netstat -antp        # Enumeración de red
ifconfig             # Redes conectadas
ip a                 # ifconfig moderno
cat /etc/hosts       # Dominios y resolución de hosts DNS
cat /etc/networks    # Redes conectadas
cat /etc/resolv.conf # Servidor DNS por defecto

Enumerar puertos abiertos ocultos de la red del target

netstat -tuln localhost
# -t TCP -u UDP -l Listener -n Name/IP

Comprobar si devuelve algo ese puerto

# Vemos si devuelve algo esa conexión al conectarnos con netcat
nc 127.0.0.1 8888
