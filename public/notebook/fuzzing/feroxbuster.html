Feroxbuster

Fuerza Bruta de directorios y extensiones php

feroxbuster -u http://10.10.11.116 -x php

Comandos

# -f: Añade / al final de cada palabra Ej. /admin /admin/
# -n: No recursivo Ej. /admin 200 OK. No sigue probando con /admin/Fuzz
# -A: Usa Agents diferentes
# -C <404>: Oculta códigos de estado
# -e: Muestra en Output la URL entera
# -b: Busca backups
# --auto-tune: Optimiza el scan automáticamente en velocidad, hilos y rendimiento
# -S 0: Muestra todas las respuestas y evita que se use un filtrado por tamaño
