post-explotación / windows / enumeración local

Sistema

La enumeración del sistema muestra versión, arquitectura, hostname, hotfixes y variables de entorno; datos necesarios para decidir pruebas posteriores.

Meterpreter

sysinfo # Arquitectura, SO, hostname
getuid # Usuario

CMD

hostname # Hostname
systeminfo # Información detallada del sistema operativo y parches instalados.

wmic os get Caption, Version, BuildNumber # Versión del sistema operativo.
wmic qfe get Caption,Description,HotFixID,InstalledOn # Ver catálogo de HotFixes
env # Variables de entorno.
