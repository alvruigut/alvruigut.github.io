Arquitectura SO (Migrar Proceso)

PowerShell: Determinar arquitectura

[Environment]::Is64BitOperatingSystem # Bits Sistema Operativo
[Environment]::Is64BitProcess         # Bits Proceso Actual

CMD: x86 a x64

%windir%\sysnative\WindowsPowerShell\v1.0\powershell.exe # PowerShell
%windir%\sysnative\cmd.exe # CMD

Concepto Procesos Solo tiene sentido migrar de x86 a x64 cuando el sistema operativo es x64, porque en un sistema x86 no hay procesos x64
