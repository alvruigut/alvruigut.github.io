Alternate Data Streams (ADS)

Los Alternate Data Streams de NTFS permiten asociar contenido adicional a un archivo. Pueden usarse para ocultar payloads en laboratorio, pero también son detectables y deben limpiarse tras la prueba.

Desde Windows, podemos crear por consola un archivo, en el que dentro realmente hay un contenido oculto.

Comandos

# Se oculta mejor en archivos Temp del sistema

# Ejemplo 1: Vemos solo windowslog.txt y no backdoor.exe
type payload.exe > windowslog.txc:backdoor.exe
# Ejemplo 2: Vemos un notas.txt
notepad notas.txt:backdoor.exe

# De esa forma veremos el archivo como un fichero de texto en el que dentro oculta otro fichero.exe

# Si queremos ejecutar el ejecutable, deberíamos crear un link simbólico desde una cmd con permisos privilegiados

mklink backdoor.exe C:\\path_to_notas.txt:backdoor.exe

# Ejecutamos backdoor.exe
backdoor.exe
