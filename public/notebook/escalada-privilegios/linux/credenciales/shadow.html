Shadow

/etc/shadow almacena hashes de contraseñas. Leerlo puede permitir cracking offline; escribirlo puede permitir cambiar credenciales, siempre dentro de un laboratorio o pentest autorizado.

Modificar /etc/shadow puede dejar usuarios sin acceso o romper autenticación. En laboratorio, guarda copia antes de tocarlo.

Fichero /etc/shadow

  • Permiso de lectura: permite volcar hashes de los usuarios para cracking offline.
  • Permiso de escritura: permite cambiar el hash de contraseña de cualquier usuario.

Cambiar contraseña a un usuario

# Crear contraseña
openssl passwd -1 -salt abc <password_123>

# Nos devuelve una cadena y lo añadimos en <password_hash> del shadow:
root:<password_hash>:<id_ultimo_cambio>:<min_dias_poder_cambiar_pass>...:

# Ya podremos acceder al usuario por ssh o con sudo su (password_123)
