Usuarios y grupos

La enumeración de usuarios, grupos y shells ayuda a entender el contexto de privilegios local y posibles rutas de movimiento o escalada dentro del host.

Meterpreter

getuid # Usuario

Bash

id               # Usuario actual
whoami           # Usuario actual
groups           # Grupos
groups root      # Grupos del usuario root
cat /etc/passwd  # Cuentas de usuario y shells asociadas
cat /etc/group   # Grupos
cat /etc/shadow  # Usuarios y Hashes

Buscar Archivos con Permisos para un usuario

find / -user root 2>/dev/null
