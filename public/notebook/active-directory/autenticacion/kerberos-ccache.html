Autenticación Kerberos con ccache

Configuración de un cliente Kerberos en Kali para obtener un TGT, guardarlo en una caché ccache y autenticarse contra servicios del dominio que admiten Kerberos.

Aviso: un fallo con usuario y contraseña no demuestra por sí solo que Kerberos sea obligatorio. Este procedimiento aplica cuando el servicio acepta Kerberos, el KDC es alcanzable y la resolución DNS y el reloj son correctos.

Kerberos identifica los servicios mediante SPN, por lo que se debe usar el nombre DNS completo del host y no su dirección IP al acceder a SMB o SSH.

Configurar resolución de nombres

# Es preferible usar el DNS del dominio. En un laboratorio también puede
# resolverse el DC de forma temporal mediante /etc/hosts:
<ip_dc> <hostname>.<domain> <hostname>

Configurar Kerberos: /etc/krb5.conf

[domain_realm]
    .<domain> = <DOMAIN>
    <domain> = <DOMAIN>
 
[libdefaults]
    default_realm = <DOMAIN>
    dns_lookup_realm = false
    dns_lookup_kdc = true
    ticket_lifetime = 24h
    forwardable = true
 
[realms]
    <DOMAIN> = {
        kdc = <HOSTNAME>.<DOMAIN>
        admin_server = <HOSTNAME>.<DOMAIN>
        default_domain = <DOMAIN>
    }

Comprobar y sincronizar el reloj

# Kerberos tolera poco desfase horario. Evitar que dos servicios intenten
# ajustar el reloj al mismo tiempo.
sudo systemctl stop systemd-timesyncd
sudo ntpdate <ip_dc>

Obtener y cargar el TGT

impacket-getTGT '<domain>/<user>:<password>' -dc-ip <ip_dc>

# Usar una ruta absoluta evita cargar por error otra caché con el mismo nombre.
export KRB5CCNAME="$(pwd)/<user>.ccache"
klist

Usar la caché Kerberos

# NetExec consume el ticket indicado por KRB5CCNAME. Usar el FQDN del host.
nxc smb <hostname>.<domain> --use-kcache

# SSH necesita autenticación GSSAPI habilitada en cliente y servidor.
# -k NO activa Kerberos: deshabilita la delegación de credenciales GSSAPI.
ssh -o GSSAPIAuthentication=yes <user>@<hostname>.<domain>

Delegación: no utilizar ssh -K salvo que sea necesario reenviar las credenciales Kerberos al servidor. La autenticación GSSAPI normal no requiere delegarlas.
