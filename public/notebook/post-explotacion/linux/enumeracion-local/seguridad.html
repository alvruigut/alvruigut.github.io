Seguridad

La configuración de seguridad local permite revisar reglas de firewall, configuración SSH y archivos sensibles accesibles según los permisos actuales.

Bash

cat /etc/shadow # Hashes de contraseñas (requiere root)
iptables -L # Reglas de firewall.
cat /etc/ssh/sshd_config # Configuración SSH
