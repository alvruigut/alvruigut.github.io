# Los puertos abiertos internamente contienen las IPS: 127.0.0.1, podemos aplicar portforwarding para acceder a ellas

Local address 0.0.0.0: Puertos en escucha de todas las interfaces (Visible desde todas las interfaces de red) Local address 127.0.0.1: Puertos en escucha localmente (Visible desde dentro de la máquina) Local address 192.168.1.1: Puertos en escucha en la red (Visible desde la misma interfaz de red)
