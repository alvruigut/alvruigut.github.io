PLUGINS

Github DB_AUTOPWN

Comandos

 # Descargar repositorio 
 wget https://raw.githubusercontent.com/hahwul/metasploit-autopwn/master/db_autopwn.rb
 
 # Mover al directorio de pluggins de metasploit
 sudo mv db_autopwn.rb /usr/share/metasploit-framework/plugins/
 
 # Abrir metasploit
 msfconsole -q
 msf6 > load db_autopwn
 msf6 > db_autopwn
 msf6 > db_autopwn -p -t -PI 445 # Buscar todos los módulos del puerto 445
