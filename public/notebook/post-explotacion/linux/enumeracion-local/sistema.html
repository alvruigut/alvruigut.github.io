Sistema

La información del sistema permite identificar arquitectura, kernel, distribución, hostname, variables de entorno y rutas disponibles para orientar la siguiente fase.

Meterpreter

sysinfo # Arquitectura, SO, hostname
getuid  # Usuario

Bash

hostname            # Hostname
uname -a            # Información del kernel y sistema operativo.
cat /etc/issue      # Arquitectura, SO
cat /etc/*release   # Arquitectura, SO
echo $PATH          # Ver cómo está el PATH.
env                 # Variables de entorno.
lscpu               # Descubrir información adicional del sistema.
