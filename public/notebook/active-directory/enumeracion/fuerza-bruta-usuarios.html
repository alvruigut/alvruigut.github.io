Fuerza bruta de usuarios

Técnicas para validar usuarios del dominio y probar credenciales conocidas o patrones controlados sin confundir enumeración con explotación.

Sincronizar el reloj

systemctl stop systemd-timesyncd
ntpdate <ip_dc>

Fuerza Bruta: Enumerar usuarios del dominio

# Si aparece el hash de ASREP-Roasting, desconfía que se pueda crackear. (hash con impacket)
kerbrute userenum --dc <dc_ip> -d <dominio> /usr/share/wordlists/SecLists/Usernames/Names/names.txt

Validar usuario

kerbrute userenum --dc <dc_ip> -d <dominio> <users_list>
